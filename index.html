대학원생 · 연구자
논문 작성과 선행연구 정리에 많은 시간을 쏟는 교육학·사회과학 연구자. 코딩 경험이 없어도 괜찮습니다.

데이터 분석 연구자
R·SPSS·Python으로 데이터를 분석하지만 코드 작성에 어려움을 느끼는 연구자. 자연어로 분석 스크립트를 만들 수 있습니다.
💡 이 가이드의 전제

코딩을 전혀 몰라도 됩니다. 터미널(검은 화면)을 처음 여는 분도 따라할 수 있도록 모든 단계를 풀어서 설명합니다.

입문 파트 — 4개 섹션

입문 파트는 아래 순서로 읽어주세요. 각 섹션은 15~30분이면 충분합니다.

입문 01

입문 02
요금제 및 플랫폼
Free / Pro / Max 비교, claude.ai · Claude Code · API 차이, 연구자 추천 선택
입문 03
설치 및 첫 실행
Mac · Windows 설치 가이드, 로그인, 첫 명령어, 트러블슈팅
입문 04
핵심 개념 용어집
Context · 세션 · CLAUDE.md · Skill · MCP · API — 연구자 관점 해설

따라하기 파트

실제 연구 시나리오를 단계별로 따라가며 Claude 활용법을 익힙니다. 입문·활용·고급 내용을 일부 이해한 분께 적합합니다.

초급 01 · 30분
설문지 만들기
연구 변수 → Likert 문항 → 내용타당도 검토
초급 02 · 20분
영문 초록 번역·교정
한국어 초록 → 저널 스타일 영문 초록
초급 03 · 40분
인터뷰 전사 → 질적 코딩
전사본 정제 → 개방코딩 → 주제 범주화
초급 04 · 60분
연구계획서 하루 만에
아이디어 → 연구 질문 → 6절 계획서 초안
중급 05 · 50분
선행연구 코드북 만들기
문헌 수집 → 정보 추출 기준 → CSV 코드북
중급 06 · 60분
패널데이터 분석
종단 데이터 구조화 → LGM/GMM → R 코드
중급 07 · 45분
논문 심사 대응 전략
심사 의견 분류 → 반박/수용 전략 → 답변서
중급 08 · 50분
문헌 메타분석 코딩
PRISMA 선별 → 효과크기 추출 → 코딩 시트
고급 09 · 30분
R 분석 코드 디버깅
오류 메시지 → 원인 진단 → 수정 코드
고급 10 · 90분
다층모형(HLM) 분석
ICC → 단계적 모형 구축 → 교차효과 → 논문 작성
고급 11 · 45분

이 가이드를 효과적으로 읽는 법

  • 처음이라면 — 입문 01부터 순서대로 읽으세요. 건너뛰지 않는 게 중요합니다.
  • 특정 주제만 필요하다면 — 목차에서 바로 해당 섹션으로 이동하세요.
  • 프롬프트 예시는 복사해서 바로 사용 — 파란 박스의 프롬프트는 Claude에 그대로 붙여넣어 사용할 수 있습니다.
  • 단축키 각주 — 활용 파트부터는 필요한 단축키가 Shift+Tab 형태로 해당 설명 옆에 표시됩니다.
  • PDF 저장 — 각 페이지를 브라우저에서 Cmd+P(Mac) / Ctrl+P(Windows)로 인쇄해 PDF로 저장할 수 있습니다.

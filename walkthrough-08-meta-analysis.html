저는 "[연구 주제]"에 관한 메타분석을 수행하려 합니다.

PICOS 기준을 활용하여 포함·배제 기준을 제안해 주세요:
- P (Population): 대상 집단
- I (Intervention/Predictor): 독립변수/처치
- C (Comparison): 비교 조건
- O (Outcome): 종속변수/결과
- S (Study design): 연구 설계 유형

또한 실용적인 배제 기준 (언어, 발행 연도, 미발표 자료 포함 여부 등)도 제안해 주세요.

추출 항목: 논문ID / 저자(연도) / 표본크기(n) / 효과크기(d 또는 r) / SE / 95%CI / 연구설계 / 조절변수 후보

효과크기가 직접 보고되지 않는 경우: t값, F값, 또는 p값에서 변환 계산도 보여주세요.

[논문 결과 섹션 붙여넣기]

Claude — 효과크기 추출 예시
Claude

논문 Kim2023: - 표본크기: n=312 - 보고된 통계: β=.34, t(310)=6.42, p<.001 - r로 변환: r = t/√(t²+df) = 6.42/√(41.2+310) = .33 - Cohen's d 변환: d = 2r/√(1-r²) = .69 - 95% CI: [.55, .83] (계산 근거 포함) - 연구설계: 횡단 상관연구 - 조절변수 후보: 교직 경력, 학교급

4
전체 코딩 시트 생성 및 이중 코딩 계획Claude
프롬프트

지금까지 추출한 모든 논문 정보를 하나의 메타분석 코딩 시트로 정리해 주세요.

포함 열: 논문ID, 저자, 연도, 학술지, 국가, 연구설계, n, d(효과크기), SE, 하한CI, 상한CI, 조절변수1, 조절변수2, 비고

추가로: 이중 코딩(inter-rater reliability)을 위해 두 번째 코더가 확인해야 할 항목과 Cohen's kappa 계산 방법도 안내해 주세요.

완료 체크리스트

  • PICOS 기반 포함·배제 기준이 문서화됨
  • 전체 검색 결과에서 PRISMA 흐름에 따라 최종 포함 논문이 선별됨
  • 20편 이상의 논문에서 효과크기가 추출됨
  • 효과크기 변환 계산 과정이 기록됨
  • 이중 코딩으로 코더 간 신뢰도가 확인됨 (κ ≥ .80 권장)
  • 코딩 시트가 R의 metafor 패키지 입력 형식으로 준비됨

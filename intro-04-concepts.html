핵심 개념 용어집

입문 04  Claude를 제대로 활용하기 위해 반드시 알아야 할 6가지 개념

Claude Code를 사용하다 보면 특정 용어가 반복해서 등장합니다. 이 용어들을 이해하면 가이드의 나머지 내용이 훨씬 명확해집니다. 각 개념을 연구자 관점에서 풀어 설명합니다.

컨텍스트 세션 CLAUDE.md Skill MCP API
🧠
컨텍스트
Context / Context Window
Claude가 현재 대화에서 기억하고 있는 내용의 총량

Claude는 대화가 길어질수록 앞에서 나눈 내용을 점점 "잊어"갑니다. 컨텍스트는 Claude가 한 번에 기억할 수 있는 정보의 한계입니다. 논문 여러 편을 동시에 분석하거나 대화가 매우 길어지면 컨텍스트가 가득 찰 수 있습니다.

🔎 연구자 비유

연구자가 책상 위에 꺼내놓을 수 있는 논문 더미의 크기. 책상이 너무 넓으면 멀리 있는 논문을 제대로 참고하기 어렵습니다.

실용적 대처법:

  • 대화가 길어지면 /compact를 입력해 컨텍스트를 요약·압축
  • 새로운 분석 주제를 시작할 땐 /clear로 컨텍스트 초기화*
    * /clear 사용 시 기존 작업 메모리 삭제, 새로운 작업 시에 활용
  • 중요한 지시사항은 CLAUDE.md 파일에 저장 (아래 설명)
💬 실제 상황

"논문 정리를 하다가 갑자기 Claude가 이전 지시사항을 잊어버린 것 같아요" → 컨텍스트가 가득 찬 것. /compact 실행 후 핵심 지시사항을 다시 알려주세요.

/compact 입력 → 대화 내용이 자동 요약됩니다
Context 61% 사용에서 20%로 압축 및 여유 공간 확보
⏱️
세션
Session
Claude Code를 실행(claude)한 순간부터 종료(/exit)까지의 작업 단위

세션이 끝나면 대화 내용은 저장되지만, Claude가 갖고 있던 실시간 컨텍스트는 사라집니다. 다음 날 다시 작업을 시작하면 새 세션이 시작됩니다.

🔎 연구자 비유

한 연구 회의(미팅). 회의가 끝나면 메모(파일)는 남지만, 그 자리의 분위기와 즉각적인 맥락은 다음 회의 때 다시 설명해야 합니다.

이전 세션 이어받기:

# 가장 최근 세션 이어받기
claude --continue

# 또는 단축 옵션
claude -c
💬 실제 상황

어제 작업하던 논문 분석을 오늘 이어서 하고 싶다면 → cd 연구폴더 후 claude --continue를 실행하세요. Claude가 이전 대화를 불러옵니다.

📋
CLAUDE.md
Project Configuration File
연구 프로젝트의 규칙과 선호사항을 저장하는 파일 — Claude의 "장기 기억"

CLAUDE.md는 연구 폴더에 만드는 특별한 텍스트 파일입니다. Claude Code를 실행할 때마다 자동으로 이 파일을 읽고, 여기 적힌 지시사항을 항상 따릅니다. 매번 같은 지시를 반복하지 않아도 됩니다.

🔎 연구자 비유

RA에게 처음 업무를 시작할 때 건네주는 "업무 매뉴얼". 한 번 작성해두면 매번 같은 설명을 반복하지 않아도 됩니다.

CLAUDE.md 만드는 방법: Claude에게 "CLAUDE.md 파일 만들어줘, 내 연구 프로젝트 설정을 담을 거야"라고 말하면 자동으로 생성해줍니다. 직접 만들고 싶다면 메모장(Windows) 또는 TextEdit(Mac)에서 파일을 만들고 이름을 CLAUDE.md로 저장하면 됩니다.

예시 내용:

💬 실제 활용 예시 — CLAUDE.md 내용

# 연구 프로젝트 설정

## 기본 규칙
- 나는 교육학 박사과정생이야. 전공은 교사교육 및 교원정책이야.
- 논문 작성 시 항상 한국어로 작성하고, APA 7판 인용 형식을 사용해.
- 학술적 문체를 유지하되, 지나치게 딱딱하지 않게 써줘.

## 폴더 구조
- papers/ : 분석할 논문 PDF
- data/ : 연구 데이터
- drafts/ : 논문 초안

## 주의사항
- 인용할 때는 반드시 실제 논문 출처를 확인하라고 알려줘.

위 내용을 CLAUDE.md 파일로 저장하면, 매 세션마다 Claude가 자동으로 읽고 따릅니다.

🔧
스킬
Skill
특정 작업 방식을 Claude에게 가르치는 "레시피 패키지"

Skill은 SKILL.md 파일이 들어있는 폴더입니다. 이 파일에 작업 지침이 담겨 있어서, Claude가 특정 상황에서 그 지침을 따라 일관된 방식으로 작업합니다. 한 번 설치하면 관련 작업을 시킬 때마다 자동으로 불러옵니다.

🔎 연구자 비유

요리 레시피처럼, Skill은 "이 재료로 이렇게 만들어라"는 지침입니다. 레시피가 있으면 매번 처음부터 설명하지 않아도 됩니다.

연구자에게 유용한 Skill 예시:

  • literature-review — 논문 검색·요약·정리 전용 워크플로우
  • academic-writing — 학술 문체 논문 초안 작성
  • citation-assistant — APA 인용 자동 생성·검증
  • quantitative-analysis — 통계 분석 코드 작성 및 해석
💬 Skill 사용 방법 (활용 파트에서 상세 설명)

Claude Code 실행 후: /literature-review 입력
→ Claude가 논문 정리 전용 모드로 전환되어 체계적으로 작업합니다.

💡 참고

Skill 설치 방법과 연구에 유용한 Skill 목록은 활용 파트 — 논문작성 세팅에서 다룹니다. 고급 파트에서는 나만의 커스텀 Skill을 만드는 법을 설명합니다.

🔌
MCP ⏭️ 입문 단계에서는 건너뛰어도 됩니다
Model Context Protocol
Claude를 외부 도구·서비스와 연결하는 표준 규격

MCP는 Claude가 외부 서비스(웹 브라우저, 파일 시스템, 데이터베이스, Zotero 등)와 통신할 수 있게 하는 연결 규격입니다. MCP 서버를 설정하면 Claude가 인터넷 검색, 파일 접근, 외부 API 호출 등을 직접 수행할 수 있습니다.

🔎 연구자 비유

도서관 사서(Claude)가 외부 데이터베이스(RISS, Zotero, 웹)에 직접 접속할 수 있는 권한카드. MCP가 없으면 사서에게 자료를 복사해서 전달해야 하지만, MCP가 있으면 사서가 직접 검색합니다.

연구자에게 유용한 MCP 예시:

  • 파일시스템 MCP — 지정한 폴더에 파일 읽기·쓰기 (Claude Code 기본 제공)
  • 웹 검색 MCP — 실시간 학술 DB 검색
  • Zotero MCP — 참고문헌 관리 프로그램과 직접 연동
  • Google Drive MCP — 구글 드라이브 파일 직접 읽기·저장
⚠️ 입문 단계에서는

MCP 설정은 입문 단계에서 필수가 아닙니다. Claude Code만으로 대부분의 연구 작업이 가능합니다. MCP 설정 방법은 활용 파트 — 연구 프로젝트 세팅과 고급 파트 — MCP 고급 설정에서 다룹니다.

⚙️
API ⏭️ 입문 단계에서는 건너뛰어도 됩니다
Application Programming Interface
코드에서 직접 Claude를 호출하는 프로그래밍 방식 연결

API는 Python·R 코드 안에서 Claude에게 직접 요청을 보내는 방법입니다. 웹 인터페이스나 터미널 없이, 코드가 자동으로 Claude를 호출하고 결과를 받아서 처리합니다. 수백 개의 논문을 자동 분류하거나 반복적인 작업을 완전 자동화할 때 사용합니다.

🔎 연구자 비유

Claude에게 직통 전화선을 연결하는 것. 전화를 걸면 바로 연결되고, 통화 내용(질문과 답변)이 자동으로 기록·처리됩니다. 단, 이 전화선을 설치하려면 약간의 기술이 필요합니다.

💡 입문 단계에서는 API 불필요

이 가이드의 입문·활용 파트는 API 없이 Claude Code만으로 진행됩니다. API 키 발급부터 Python 코드 실습까지는 고급 06 — Claude API 시작하기에서 다룹니다. 지금 당장 이해할 필요는 없습니다.

🔀
병렬 작업
Parallel Work
여러 작업을 동시에 처리해 전체 소요 시간을 줄이는 방식

독립적인 논문 5편을 하나씩 분석하면 5번 기다려야 하지만, 한 번에 지시하면 Claude가 동시에 처리합니다. CLI를 여러 개 열어 완전히 독립된 병렬 작업도 가능합니다.

처음에는 순차 작업으로도 충분합니다. 대규모 자동화가 필요해지면 → 고급 02 Worktree 병렬 작업에서 자세히 다룹니다.

Claude가 만들 수 있는 것들

활용 06  입력 재료 · 출력 파일 · 작업 방식 — 세 가지 재료로 나만의 워크플로우를 설계합니다.

Claude Code의 강점은 기능이 많다는 것이 아닙니다. 재료들을 자유롭게 조합할 수 있다는 것입니다. 정해진 정답은 없습니다. 내 연구 방식, 작업 패턴, 선호에 따라 조합을 달리하면 됩니다. 이 페이지는 그 재료들을 한눈에 정리한 지도입니다.

💡 이 페이지를 보는 방법

재료 ① 입력 · ② 출력 · ③ 작업 방식을 각각 파악한 뒤, 레시피 섹션에서 조합 예시를 확인하세요. 그리고 체크리스트로 나에게 맞는 조합을 찾아보세요.

1. 재료 ① — Claude에게 줄 수 있는 것들

Claude는 텍스트만 받는 게 아닙니다. 다양한 형태의 입력을 이해하고 처리할 수 있습니다.

💬
텍스트 프롬프트
가장 기본적인 입력. 지시, 질문, 배경 설명 모두 텍스트로 전달합니다.
📄
파일
.pdf .csv .txt .md .r .py
논문 PDF, 설문 데이터, 전사 파일, 분석 코드 등을 직접 읽어서 처리합니다.
🖼️
이미지
.png .jpg
그래프, 표 스크린샷, 논문 본문 캡처 등을 분석하거나 내용을 추출합니다.
🧠
CLAUDE.md
영구 컨텍스트
세션이 바뀌어도 사라지지 않는 배경 지식. 연구 맥락, 문체, 실수 기록을 저장합니다.
🔌
외부 서비스 (MCP)
웹 검색 · Zotero · Notion
MCP를 연결하면 Claude가 직접 외부 데이터를 가져올 수 있습니다. 고급 04 참조
📂
폴더 전체
프로젝트 맥락
프로젝트 폴더 안에서 시작하면 Claude가 모든 파일의 구조와 관계를 파악합니다.

2. 재료 ② — Claude가 만들어주는 파일들

Claude Code는 텍스트 응답뿐 아니라 실제 파일을 직접 생성하거나 외부 도구를 통해 변환할 수 있습니다. 크게 6개 카테고리로 나뉩니다.

📝
텍스트 · 마크다운
.md .txt
논문 초안, 연구 메모, 요약문, 코드북 등 모든 글쓰기 산출물의 기본 형태.
⚡ 직접 생성 (별도 도구 불필요)
🌐
웹 파일
.html .css .js
인터랙티브 보고서, 시각화 대시보드, 학술 자료 등 브라우저에서 바로 여는 파일.
⚡ 직접 생성
📊
데이터 파일
.csv .json .yaml .xml
코딩 결과, 분석 산출물, 설정 파일. 다른 프로그램(R, Excel)과 바로 연동됩니다.
⚡ 직접 생성
💻
코드 · 스크립트
.py .r .sh .ipynb
데이터 분석 코드, 자동화 스크립트, Jupyter 노트북. 직접 실행까지 가능합니다.
⚡ 직접 생성 + 실행
📃
문서 파일
.docx .pdf
투고 논문 최종본, 보고서. pandoc을 통해 마크다운 → Word/PDF로 변환합니다.
🔧 pandoc 경유 (설치 필요)
🎞️
프레젠테이션
.pptx reveal.js
학회 발표 슬라이드, 수업 자료. python-pptx 또는 HTML 슬라이드로 생성합니다.
🔧 python-pptx 또는 HTML 경유
💡 연구자에게 가장 자주 쓰이는 조합

논문 초안은 .md로 작성 → 최종 제출 시 pandoc으로 .docx 변환 → 학회 발표는 .pptx나 HTML 슬라이드로. 데이터 분석은 .r 또는 .py로 코드 작성 → 결과는 .csv로 저장하는 흐름이 일반적입니다.

3. 재료 ③ — 어떻게 시킬 수 있나 (작업 방식)

같은 결과물도 어떤 방식으로 작업하느냐에 따라 효율이 달라집니다. 다섯 가지 작업 방식이 있습니다.

기본 대화
한 창에서 순차적으로 대화하며 작업
가장 직관적인 방식. 짧은 작업, 처음 시작할 때 적합합니다.
→ 활용 02
플랜 모드
먼저 계획 → 확인 후 실행
Shift+Tab으로 전환. 복잡한 작업에서 버그→수정→꼬임 악순환을 막습니다.
→ 활용 02
병렬 터미널
터미널 여러 개를 동시에 띄워 병렬 작업
문헌 검색 + 논문 작성 + 데이터 분석을 동시에. 5시간 → 1~2시간으로 단축.
→ 고급 02
Hooks 자동화
특정 행동에 자동 반응하는 시스템 구성
파일 저장 시 자동 백업, 작업 완료 시 자동 Git 커밋 등. 실수를 시스템이 차단합니다.
→ 고급 05
커스텀 스킬
반복 작업을 슬래시 명령어 하나로 자동 실행
하루 2번 이상 하는 작업은 스킬로 만들어두면 버튼 하나로 끝납니다.
→ 고급 03

4. 조합 예시 — 연구자 레시피

입력 재료 + 출력 형태 + 작업 방식을 조합하면 나만의 워크플로우가 됩니다. 아래는 교육학 연구자에게 자주 맞는 조합 예시입니다.

📚 레시피 A — 문헌 검토
입력 논문 PDF 여러 편, 검색 키워드
출력 .csv요약표 .md문헌 검토 초안 .docx최종본
방식 병렬 터미널 (논문 수집과 요약 동시 진행)
팁 10편 이상이면 분할 요청. RISS 수집기로 초기 데이터 확보.
🎤 레시피 B — 질적 연구
입력 인터뷰 녹음 전사 파일(.txt), 코드북
출력 .csv코딩 결과 .md주제 분석 .pptx발표 자료
방식 플랜 모드 → 코딩 설계 확인 후 실행
팁 CLAUDE.md에 코드 정의 저장 → 세션마다 일관된 코딩.
✍️ 레시피 C — 논문 작성
입력 분석 결과(.csv), CLAUDE.md(문체·스타일)
출력 .md초안 (장별) .docx투고본 .bib참고문헌
방식 기본 대화 + 학습 루프(CLAUDE.md 실수 기록)
팁 APA 스킬 등 반복 작업은 커스텀 스킬로 만들어두기.
⚙️ 레시피 D — 반복 업무 자동화
입력 반복적인 작업 패턴
출력 .md주차별 리플렉션 .csv논문 분류 결과
방식 커스텀 스킬 + Hooks + 병렬 터미널
팁 하루 2번 이상 하는 작업은 무조건 스킬로 만드세요.

5. 나만의 조합 찾기 — 여정으로서의 활용

7가지 방법을 다 외울 필요 없습니다. Claude Code를 만든 사람도, 해커톤 1등도 결국 자기에게 맞는 시스템을 찾아가는 과정이 핵심이었습니다. 이 재료들은 그 여정에서 가장 확실한 이정표입니다.

지금 당장 모든 걸 쓸 필요는 없습니다. 아래 체크리스트로 나에게 해당되는 상황을 확인하고, 그것부터 시작해보세요.

📄 주로 문서를 만든다
  • 논문 초안, 보고서를 자주 씁니다
  • 형식과 문체를 일관되게 유지하고 싶습니다
  • Word 파일 최종본이 필요합니다
→ 시작: CLAUDE.md 학습 루프 + .md → .docx 흐름
📊 데이터 분석을 한다
  • R이나 Python으로 분석합니다
  • 같은 분석을 여러 번 반복합니다
  • 결과를 표나 그래프로 정리합니다
→ 시작: 코드 .r/.py 생성 + 결과 .csv 저장 흐름
⏱️ 반복 작업이 많다
  • 매주 같은 형태의 자료를 만듭니다
  • 비슷한 프롬프트를 반복 입력합니다
  • 여러 작업을 동시에 처리하고 싶습니다
→ 시작: 커스텀 스킬 + 병렬 터미널
🎯 복잡한 작업을 설계한다
  • 큰 프로젝트를 단계별로 진행합니다
  • 실수나 꼬임이 걱정됩니다
  • 품질 검증이 중요합니다
→ 시작: 플랜 모드 + 검증 루프(성공 기준 먼저 설정)
✅ 이 장을 마쳤다면

Claude가 받을 수 있는 입력(6종), 만들어줄 수 있는 출력(6개 카테고리), 작업 방식(5가지)을 이해했습니다. 이제 이 재료들을 조합해서 논문 작성 환경을 본격적으로 세팅해봅니다.

설치 및 첫 실행

입문 03  Mac · Windows 설치 단계별 안내 및 첫 실행 확인

1. 시작 전 확인 사항

Claude Code를 설치하려면 아래 조건이 갖춰져 있어야 합니다. 하나씩 확인해보세요.

  • 🌐
    Claude 계정 (Pro 이상)
    claude.ai에서 회원가입 후 Pro 플랜 구독이 필요합니다. 아직 구독 전이라면 입문 02를 먼저 확인하세요.
  • 🟢
    Node.js 18 이상
    Claude Code는 Node.js 환경에서 실행됩니다. 아직 설치되어 있지 않아도 됩니다 — 아래 설치 단계에 포함되어 있습니다.
  • 💾
    저장 공간 약 500MB 이상
    Node.js와 Claude Code 설치에 필요합니다. 실제 연구 파일은 별도입니다.
  • 📡
    안정적인 인터넷 연결
    Claude는 클라우드 기반으로 작동합니다. 인터넷이 연결된 환경에서 사용하세요.

2. 설치 단계별 가이드

운영체제를 선택하면 해당 안내가 표시됩니다.

  1. 터미널 열기

    Cmd + Space를 누르고 "터미널" 또는 "Terminal"을 입력 후 실행합니다.
    또는 Finder → 응용 프로그램 → 유틸리티 → 터미널

    💡 터미널이 처음이라면

    검은 화면에 흰 글씨가 나타나면 정상입니다. 명령어를 입력하고 Enter를 누르면 실행됩니다.

  2. Node.js 설치 확인

    터미널에 아래 명령어를 입력해 Node.js가 이미 설치되어 있는지 확인합니다.

    node --version

    v18.0.0 이상이 표시되면 ✅ 이미 설치됨 → 3단계로 이동
    command not found가 표시되면 → 아래에서 설치

  3. Node.js 설치 (없는 경우)

    방법 A — 공식 사이트 코딩 경험 없다면 이 방법 추천
    nodejs.org에서 LTS 버전 다운로드 후 설치 파일 실행합니다.

    방법 B — Homebrew (터미널에 익숙하다면 펼치기) 
    # Homebrew가 없으면 먼저 설치
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Node.js 설치
brew install node

    설치 후 node --version으로 다시 확인합니다.

  4. Claude Code 설치

    npm install -g @anthropic-ai/claude-code

    설치가 완료되면 아래 명령어로 버전을 확인합니다.

    claude --version

  5. 로그인

    아래 명령어를 실행하면 브라우저가 자동으로 열립니다.

    claude

    Claude.ai 계정으로 로그인 → 인증 완료 → 터미널로 돌아오면 준비 완료입니다.

  1. PowerShell 열기

    Windows 키를 누르고 "PowerShell"을 검색 → Windows PowerShell 마우스 우클릭 → "관리자 권한으로 실행"

    💡 Windows Terminal 사용 권장

    Microsoft Store에서 "Windows Terminal"을 무료로 설치하면 더 편리하게 사용할 수 있습니다. PowerShell 탭을 열어 사용하세요.

  2. Node.js 설치 확인

    node --version

    v18.0.0 이상이면 ✅ 이미 설치됨 → 3단계로 이동
    오류가 나오면 → 아래에서 설치

  3. Node.js 설치 (없는 경우)

    nodejs.org → 상단의 LTS 버전 다운로드 클릭 → .msi 파일 실행 → 설치 마법사 따라 진행

    설치 완료 후 PowerShell을 다시 열고 버전 확인:

    node --version

  4. Claude Code 설치

    npm install -g @anthropic-ai/claude-code
    ⚠️ 실행 정책 오류 발생 시

    PowerShell에서 "이 시스템에서 스크립트 실행이 비활성화되어 있습니다" 오류 발생 시:

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

    이후 다시 npm install 명령어를 실행하세요.

  5. 로그인

    claude

    브라우저가 열리면 Claude.ai 계정으로 로그인합니다. 인증 완료 후 터미널로 돌아오면 준비 완료입니다.

3. 첫 실행 — 이렇게 시작합니다

터미널이 열려 있으면 claude를 입력하고 Enter를 누르는 것만으로 시작됩니다. 연구 폴더로 이동하는 방법은 아래 4절에서 다룹니다.

Terminal — 첫 실행 4단계
# 1단계: claude 입력
$ claude

# 2단계: 보안 신뢰 확인 (최초 1회만 나타납니다)
Accessing workspace:
/Users/researcher
Quick safety check: Is this a project you created or trust?
1. Yes, I trust this folder
2. No, exit

# 3단계: 실행 완료 — 버전·플랜 확인
Claude Code v2.1.92
Sonnet 4.6 · Claude Pro

# 4단계: 프롬프트에 첫 질문 입력
Claude> 안녕, 나는 교육학 박사과정생이야. 이 폴더에 있는 파일들을 함께 분석할 거야.

안녕하세요! 폴더를 확인해볼게요. papers/ 폴더에 PDF 파일이 5개 있고...

실제 실행 화면 — 단계별

아래는 터미널에서 claude를 입력하고 시작하는 실제 화면입니다.

① 터미널 실행 — 빈 zsh 프롬프트
② claude 입력 후 Enter
③ 보안 신뢰 확인 (최초 실행 시 1회)
④ Claude Code 준비 완료 — 프롬프트 입력 가능
💡 보안 신뢰 확인이란?

Claude가 이 폴더 안의 파일을 읽고 수정할 수 있도록 허용하는 절차입니다. 보안 위험이 아니라, 내 연구 폴더에 접근 권한을 주는 것입니다. 내 연구 폴더라면 "1. Yes, I trust this folder"를 선택하세요. 이 확인은 폴더를 처음 열 때만 나타납니다.

작업 중 화면 예시

Claude Code는 파일 작성, 명령 실행, 결과 보고를 한 화면에서 순서대로 보여줍니다.

Claude가 HTML 파일을 생성하고 내비게이션을 업데이트하는 실제 작업 화면

기억해야 할 핵심 3가지

  • 항상 연구 폴더에서 시작 — cd 폴더경로 후 claude
  • 이전 세션 이어받기 — claude --continue 또는 claude -c
  • 종료 — Ctrl+C 또는 대화창에 /exit 입력

Claude Code를 실행한 후, 아래 프롬프트를 그대로 입력해보세요:

이 폴더의 파일 목록을 확인하고, 어떤 파일들이 있는지 설명해줘.

✅ 예상 결과

Claude가 현재 폴더의 파일들을 스캔하고, 각 파일의 종류와 내용을 요약해서 설명합니다. 연구 폴더가 비어 있어도 정상적으로 응답합니다.

4. 자주 발생하는 오류 해결법

❌ "command not found: claude"

원인: Claude Code가 설치되지 않았거나 경로가 등록되지 않음

해결: npm install 명령어를 다시 실행하세요.

npm install -g @anthropic-ai/claude-code

Mac에서 Homebrew로 Node.js를 설치한 경우, 터미널을 완전히 닫고 다시 열어보세요.

❌ "Authentication required" / 로그인 안 됨

원인: 로그인 세션이 만료되었거나 계정 문제

해결: 아래 명령어로 다시 로그인하세요.

claude login

Pro 플랜 구독이 활성화되어 있는지도 확인하세요 (claude.ai → 설정 → 구독).

❌ npm 설치 중 "EACCES: permission denied"

원인: npm 전역 설치 권한 문제 (Mac에서 주로 발생)

해결:

# npm 전역 설치 디렉토리를 사용자 폴더로 변경
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'

# ~/.zshrc 또는 ~/.bash_profile에 경로 추가
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc
source ~/.zshrc

# 다시 설치
npm install -g @anthropic-ai/claude-code
❌ Windows: "실행 정책" 오류

원인: Windows의 기본 보안 정책이 스크립트 실행을 차단

해결: PowerShell을 관리자 권한으로 열고 실행:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

이후 npm install -g @anthropic-ai/claude-code를 다시 실행하세요.

💡 그래도 해결되지 않는다면

오류 메시지 전체를 복사해서 Claude.ai 웹(claude.ai) 채팅창에 붙여넣고 "이 오류 해결 방법 알려줘"라고 물어보면 단계별 안내를 받을 수 있습니다.

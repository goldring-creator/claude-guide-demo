입문 02  어떤 요금제가 필요한지, 어떤 플랫폼을 써야 하는지 결정합니다

1. 요금제 비교 (Free · Pro · Max)

Claude는 세 가지 요금제를 제공합니다. 연구 목적으로 Claude Code (CLI)를 사용하려면 최소 Pro 플랜이 필요합니다.

Free
무료
  • claude.ai 웹 접근
  • 기본 대화 기능
  • Claude Code (CLI) 사용 불가
  • Skill 사용 불가
  • 사용량 제한 (하루 수십 회)
Pro
$20 / 월 (약 2.8만원)
  • claude.ai 웹 고용량 접근
  • Claude Code (CLI) 사용 가능
  • Skill 설치·사용 가능
  • MCP 연동 가능
  • 우선 접근권 (트래픽 혼잡 시)
  • 사용량 한도 존재
Max
$100 / 월 (약 14만원)
  • Pro의 모든 기능
  • 5배 높은 사용량 한도
  • 대용량 연구 프로젝트에 적합
  • 긴 논문·데이터 집중 분석
  • $200/월 플랜: 5x 추가 용량
💡 연구자 추천

처음 시작: Pro ($20/월)로 시작하세요. 대부분의 선행연구 정리·논문 작성 작업에 충분합니다.

대규모 데이터 분석: 패널 데이터 분석이나 논문 여러 편을 동시에 처리한다면 Max를 고려하세요.

⚠️ 요금 변동 가능성

위 금액은 2025~2026년 기준이며 Anthropic 정책에 따라 변경될 수 있습니다. 최신 요금은 claude.ai/pricing에서 확인하세요.

사용량 한도 — 두 가지 구분

구독 플랜에는 사용량 한도가 있습니다. 설정 앱에서 두 가지 유형을 확인할 수 있습니다: 플랜 사용량과 추가 사용량.

📊 플랜 사용량 한도

월 구독료에 포함된 기본 사용량. 두 가지 한도가 동시에 적용됩니다.

  • 현재 세션 한도: 약 2시간 단위로 리셋. 세션 중 집중 작업 시 소진 가능.
  • 주간 한도: 모든 모델 합산 + Sonnet 별도 추적. 초과 시 일시 중단.
확인 경로: 설정 앱 → 사용량 → 플랜 사용량 한도
💳 추가 사용량 (선택)

플랜 한도를 모두 소진한 후에도 계속 사용하려면 활성화하는 옵션.

  • 사용한 토큰 양만큼 별도 과금 (API 방식).
  • 월간 지출 한도를 직접 설정해 과금 상한선 관리 가능.
  • 기본값은 꺼짐. 켜지 않으면 한도 초과 시 중단됩니다.
확인 경로: 설정 앱 → 사용량 → 추가 사용량
💡 연구 작업 중 한도 초과 시 대처법

논문 10편 분석·긴 데이터 처리 등 장시간 작업은 세션 한도를 소진할 수 있습니다.

방법 A (무료): 세션 한도 리셋(~2시간 후)을 기다렸다가 재개합니다. 그 사이 다른 작업을 하면 됩니다.

방법 B (유료): 설정 → 사용량 → 추가 사용량을 켜두면 한도 초과 후에도 중단 없이 계속 작업할 수 있습니다.

2. 플랫폼 비교 — 4가지 접근 방법

Claude를 사용하는 방법은 네 가지입니다. 이 가이드는 Claude Code (CLI)를 중심으로 설명합니다.

🌐
claude.ai 웹/데스크탑 앱
브라우저 또는 전용 앱으로 사용

가장 쉽게 접근할 수 있는 인터페이스. 대화형 질문·답변에 최적화.

  • 웹: 설치 불필요, 브라우저 접속만 (claude.ai)
  • 데스크탑 앱: Mac/Windows 전용 앱 설치 (claude.ai/download)
  • 파일 업로드 가능 (PDF, 이미지)
  • 결과가 파일로 저장되지 않음
  • 적합한 작업: 빠른 질문, 번역, 아이디어 정리
⌨️
Claude Code (CLI) 이 가이드 중심
터미널 기반 에이전트

내 컴퓨터 폴더에서 직접 작동하는 AI 에이전트. 파일 읽기·쓰기·분석 가능.

  • Pro/Max 플랜 필요
  • 터미널에서 claude 명령어로 실행
  • 결과가 실제 파일로 저장됨
  • R, Python 스크립트 직접 실행
  • Skill, MCP 연동 가능
  • 적합한 작업: 연구 전반 (선행연구~논문)

💡 Claude Code (CLI)는 웹(claude.ai/code)·데스크탑 앱·IDE 확장으로도 접근 가능. 단, 로컬 파일 직접 접근과 자동화 기능은 CLI에서만 완전 지원됩니다.

👥
Claude.ai Coworker
웹 기반 고급 에이전트

claude.ai에서 파일을 업로드하고 다중 단계 작업을 시킬 수 있는 웹 에이전트 기능.

  • 브라우저에서 사용 (설치 불필요)
  • 파일 업로드·다운로드 지원
  • Claude Code (CLI)보다 접근이 쉬움
  • 단, 내 컴퓨터 파일 직접 접근 불가
  • 적합한 작업: 간단한 다단계 문서 작업
🔌
API
개발자용 직접 연결

Python·R 등의 코드에서 Claude를 직접 호출하는 방식. 자동화·대규모 처리에 사용.

  • 별도 API 키 발급 필요 (유료)
  • 사용량만큼 과금 (토큰 단위)
  • 코딩 지식 필요
  • 적합한 작업: 수백 건 논문 자동 분류 등 대규모 자동화

4. 웹·앱이 있는데 왜 CLI를 설치하나요?

Claude Code (CLI)는 웹·데스크탑 앱으로도 사용할 수 있습니다. 그럼에도 이 가이드가 CLI를 중심으로 하는 이유가 있습니다.

📁 내 파일에 바로 접근

로컬 폴더를 그대로 작업 공간으로 사용합니다. 매번 업로드·다운로드가 필요 없습니다.

웹·Coworker → 파일을 매번 업로드, 결과는 복사-붙여넣기 CLI → 내 폴더에서 바로 읽고, 결과가 즉시 파일로 저장
🖥️ 노트북 자원 절약

터미널 프로세스 하나만 실행됩니다. 브라우저나 Electron 앱보다 훨씬 가볍습니다.

웹·데스크탑 앱 → 브라우저/앱 실행 → RAM·CPU 점유 CLI → 터미널 프로세스 하나 → 장시간 작업에 유리
🔁 반복 설명 없이 효율적

CLAUDE.md에 연구 맥락·규칙을 저장하면 매 세션 자동으로 로드됩니다.

웹·앱 → 대화 시작마다 "나는 교육학 연구자고..." 재설명 CLI → CLAUDE.md 한 번 작성 → 이후 자동 적용
⚙️ R·Python 직접 실행

분석 스크립트를 Claude가 직접 돌리고 결과를 바로 처리합니다.

웹·Coworker → 스크립트 실행 불가 CLI → R/Python 명령 직접 실행, 출력 결과 즉시 분석

작업 유형별 추천

웹·앱으로 충분 빠른 질문·번역, 단발성 문서 정리, 파일이 없는 짧은 작업
CLI 권장 논문 분석·작성, 데이터 처리, 반복되는 연구 작업, 장시간 세션

5. 나에게 맞는 선택은?

처음 시작이라면
Pro 플랜 + claude.ai 웹 또는 데스크탑용 앱으로 시작하세요. 설치 없이 바로 Claude를 경험할 수 있습니다.
⭐ 이 가이드 추천: Pro 플랜 + Claude Code (CLI) — 파일 처리·자동화 등 연구 전반을 가장 효율적으로 활용할 수 있는 조합입니다.
설치하기 어렵다면
claude.ai 웹/앱 또는 Coworker를 먼저 경험해보세요. 핵심 기능을 익힌 후 Claude Code (CLI)로 전환하면 진입 장벽이 낮아집니다.
논문 PDF 20편 이상 분석
Claude Code (CLI)가 필수입니다. 폴더의 파일을 일괄 처리할 수 있어 수십 편도 한 번에 정리합니다.
R·SPSS 데이터 분석
Claude Code (CLI)가 R 스크립트를 작성하고 직접 실행합니다. 결과는 CSV·Word·PDF로 저장됩니다.
대규모 자동화 (수백 건)
API를 고려하세요. 다만 Python 코딩 지식이 필요합니다. 고급 파트에서 다룹니다.

요금제: Pro · 플랫폼: Claude Code (CLI) · 운영체제: Mac 또는 Windows

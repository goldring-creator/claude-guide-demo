2. R 출력 결과를 Claude에게 효율적으로 전달하기

Claude와의 분석 협업에서 가장 중요한 기술 중 하나가 R 출력 결과를 정확하게 전달하는 것입니다. 아래 두 방법을 사용하세요.

콘솔에 출력된 결과를 파일로 저장해 Claude에게 전달하는 가장 간단한 방법입니다.

# 분석 결과를 텍스트 파일로 저장
capture.output(
  summary(fit_cfa, fit.measures = TRUE, standardized = TRUE),
  file = "03_analysis/output/cfa_result.txt"
)

# 여러 결과를 한 파일에 저장
capture.output(
  cat("=== 적합도 지수 ===\n"),
  fitMeasures(fit_cfa, c("cfi.robust", "tli.robust", "rmsea.robust", "srmr")),
  cat("\n=== 요인부하량 ===\n"),
  parameterEstimates(fit_cfa, standardized = TRUE),
  file = "03_analysis/output/cfa_full.txt"

3. 위계적 회귀분석 — 변수 투입 순서와 ΔR²

교육학 연구에서 가장 흔한 분석 중 하나가 위계적 회귀분석(Hierarchical Regression)입니다. 변수를 이론적 근거에 따라 단계별로 투입하고 각 단계의 설명력 변화(ΔR²)를 확인합니다.

1
1단계: 통제변수 투입
성별, 경력, 학교급 등 종속변수에 영향을 미칠 수 있는 변수를 먼저 통제. 이 단계의 R²가 통제변수만으로 설명되는 분산.
2
2단계: 주요 독립변수 투입
연구가설의 핵심 변수 투입. ΔR²(1→2단계)가 독립변수의 고유 설명력.
3
3단계 (선택): 조절변수 또는 추가 변수
조절효과 검증 시 상호작용항 투입. ΔR²(2→3단계)가 조절효과의 설명력.
✍️ 프롬프트 예시 — 위계적 회귀분석

02_data/survey_clean.csv 로 위계적 회귀분석 R 코드를 만들어줘.
종속변수: burnout_exhaustion (정서적 탈진)
1단계 통제변수: gender, years_exp, school_type
2단계 독립변수: job_demand_time, job_demand_admin (직무 요구)
3단계 독립변수: job_resource (직무 자원), job_demand_time × job_resource (조절효과)

각 단계마다: R², ΔR², F변화량, 각 변수 β값, VIF 다중공선성 진단
조절효과는 표준화된 변수로 상호작용항 만들어줘 (multicollinearity 방지)
결과를 03_analysis/04_hierarchical_reg.R 로 저장해줘.

# 위계적 회귀분석 — 교사 소진 예측
library(dplyr); library(car)

# 조절효과용 표준화 (평균중심화)
dat <- dat |>
  mutate(
    demand_c   = scale(job_demand_time, scale = FALSE),
    resource_c = scale(job_resource,    scale = FALSE),
    interaction = demand_c * resource_c
  )

# 단계별 모형 구성
m1 <- lm(burnout_exhaustion ~ gender + years_exp + school_type,          data = dat)
m2 <- lm(burnout_exhaustion ~ gender + years_exp + school_type +
          job_demand_time + job_demand_admin,                               data = dat)
m3 <- lm(burnout_exhaustion ~ gender + years_exp + school_type +
          demand_c + job_demand_admin + resource_c + interaction,          data = dat)

# R² 변화량 확인
anova(m1, m2, m3)  # F변화량 유의성

# 각 단계 요약
summary(m1); summary(m2); summary(m3)

# 다중공선성 진단
vif(m2)  # VIF > 10이면 문제

4. 확인적 요인분석(CFA)

✍️ 프롬프트 예시 — CFA

MBI-ES 척도(22문항, 3요인: 탈진 e1~e9, 냉담 c1~c5, 성취감 pe1~pe8)를 CFA로 검증하는 R 코드를 만들어줘. lavaan 패키지.
- 3요인 상관 모형
- 비정규성에 강건한 MLR 추정
- 적합도 지수: CFI.robust, TLI.robust, RMSEA.robust (90% CI), SRMR
- 요인부하량, 오차공분산, omega 신뢰도
- 수렴타당도(AVE ≥ .50, CR ≥ .70) 및 판별타당도(AVE > r²) 확인
코드는 03_analysis/02_cfa.R 로 저장해줘.

# CFA — 교사 소진 측정 모형 (MBI-ES 3요인)
library(lavaan); library(semTools)

model_cfa <- '
  exhaustion =~ e1+e2+e3+e4+e5+e6+e7+e8+e9
  cynicism   =~ c1+c2+c3+c4+c5
  efficacy   =~ pe1+pe2+pe3+pe4+pe5+pe6+pe7+pe8
'

fit_cfa <- cfa(model_cfa, data = dat, estimator = "MLR")

fitMeasures(fit_cfa, c("cfi.robust", "tli.robust",
                        "rmsea.robust", "rmsea.ci.lower.robust",
                        "rmsea.ci.upper.robust", "srmr"))

# 수렴타당도: AVE, CR
reliability(fit_cfa)  # semTools: omega, AVE

5. 잠재프로파일분석(LPA) — 프로파일 수 결정 기준

LPA에서 가장 중요한 결정은 몇 개의 프로파일이 최적인가입니다. 단일 기준이 아니라 아래 4가지 지표를 종합적으로 검토해야 합니다.

지표기준값해석주의사항
BIC
(Bayesian Information Criterion)		 낮을수록 좋음 프로파일 수가 증가해도 BIC가 크게 줄지 않는 "엘보(elbow)" 지점 선택 표본이 클수록 더 많은 프로파일을 선호하는 경향
Entropy ≥ 0.80 권장 각 사례가 프로파일에 명확히 분류되는 정도. 1에 가까울수록 선명한 분류 낮은 Entropy도 이론적으로 의미 있는 프로파일이면 선택 가능
LMR-LRT
(Lo-Mendell-Rubin 검정)		 p < .05 k-1개보다 k개 프로파일이 통계적으로 더 나은지 검증 tidyLPA에서는 BLRT 사용 권장 (더 강건함)
해석 가능성 이론적 부합 각 프로파일이 연구 이론 및 선행연구와 의미 있게 연결되는가 통계 지표가 좋아도 해석 불가능하면 선택 지양
💡 기준이 엇갈릴 때 의사결정 규칙

BIC, Entropy, LMR-LRT, 해석 가능성 중 3가지 이상이 유리한 모델을 선택하세요. 기준이 충돌하면 이론적 해석 가능성을 우선합니다. 예: BIC는 4프로파일, Entropy는 3프로파일 지지 → 이론적으로 더 의미 있는 쪽 선택.

✍️ 프롬프트 예시 — LPA (프로파일 수 결정 포함)

교사 소진 3하위척도(탈진, 냉담, 성취감)로 LPA를 실시하는 R 코드를 만들어줘. tidyLPA 패키지.
- 2~6 프로파일 모형 비교
- 각 모형의 BIC, Entropy, BLRT p값을 한 표로 정리
- "elbow plot" (BIC 변화 그래프) 생성
- 최적 프로파일 선정 후: 프로파일별 평균 및 SE 시각화 (ggplot2 막대+오차막대)
- 각 사례의 프로파일 소속(가장 높은 사후확률 기반)을 원 데이터에 병합
코드는 03_analysis/03_lpa.R 로 저장해줘.

# LPA — 프로파일 수 비교
library(tidyLPA); library(ggplot2)

# 2~6 프로파일 비교
lpa_compare <- dat |>
  select(exhaustion, cynicism, efficacy) |>
  estimate_profiles(2:6)

# 비교 지표 표
compare_solutions(lpa_compare, statistics = c("AIC", "BIC", "Entropy", "BLRT_p"))

# 최적 모형 선택 (예: 4 프로파일)
best_model <- dat |>
  select(exhaustion, cynicism, efficacy) |>
  estimate_profiles(4)

# 프로파일 분류 결과를 원 데이터에 병합
dat_lpa <- get_data(best_model)
dat$profile <- dat_lpa$Class

6. 매개효과 검증 — 부트스트랩 간접효과

교육학 연구에서 자주 나타나는 직무요구 → 소진 매개변수 → 결과 구조의 매개효과를 lavaan으로 검증합니다. 부트스트랩(Bootstrap)이 Sobel 검정보다 신뢰성이 높습니다.

✍️ 프롬프트 예시 — 매개효과 (lavaan)

직무요구(job_demand) → 감정적 소진(exhaustion) → 이직의도(turnover_intention) 매개 경로를 lavaan으로 검증하는 R 코드를 만들어줘.
- 완전/부분 매개 모형 비교
- 부트스트랩 간접효과 (5000회, 95% CI)
- 직접효과(c'), 간접효과(a×b), 총효과(c) 모두 보고
- APA 형식으로 결과 서술 초안도 작성해줘
코드는 03_analysis/05_mediation.R 로 저장해줘.

# 매개효과 — 부트스트랩 간접효과
library(lavaan)

model_med <- '
  exhaustion ~ a * job_demand
  turnover   ~ b * exhaustion + cp * job_demand

  indirect := a * b
  direct   := cp
  total    := cp + a * b
'

fit_med <- sem(model_med, data = dat,
              se = "bootstrap", bootstrap = 5000, seed = 42)

parameterEstimates(fit_med, ci = TRUE, level = 0.95,
                    boot.ci.type = "bca.simple")

Claude — 진단 및 수정 예시
Claude — 원인 진단

이 오류는 공분산 행렬이 양정치(positive definite) 조건을 만족하지 않을 때 발생합니다. 주요 원인은 3가지입니다: 1. 변수 간 다중공선성 (r > .95 수준의 높은 상관) 2. 결측값이 처리되지 않은 상태로 모형 추정 3. 표본 크기에 비해 추정 모수가 너무 많음 먼저 아래 진단 코드를 실행해보세요:

Claude — 진단 코드

# 1. 결측값 확인 colSums(is.na(df[, model_vars])) # 2. 상관행렬에서 극단적 상관 확인 cor_mat <- cor(df[, model_vars], use = "complete.obs") which(abs(cor_mat) > .95 & cor_mat != 1, arr.ind = TRUE) # 3. 완전한 케이스만으로 재시도 df_complete <- df[complete.cases(df[, model_vars]), ] model <- cfa(model_syntax, data = df_complete, estimator = "MLR")

수정 적용 후 새 오류 발생 시 반복연구자

진단 코드를 실행하고 나온 결과를 다시 Claude에 공유하면 2차 진단을 받을 수 있습니다. 이 과정을 오류가 해소될 때까지 반복합니다.

완료 체크리스트

  • 오류 메시지의 의미를 이해함 (단순 복사·붙여넣기가 아님)
  • 수정된 코드가 실행되어 오류가 해소됨
  • 수정 이유를 코드 주석으로 기록함
  • 동일 오류 재발 예방 코드(데이터 검증)가 스크립트에 포함됨
  • 최종 분석 결과가 예상 범위 내에 있는지 상식 확인(sanity check)을 함

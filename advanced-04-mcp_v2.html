MCP 고급 설정

고급 04  v2  Claude Code CLI vs Desktop 설정 경로 구분, Brave Search 상세 단계, 연결 확인 방법 강화

MCP(Model Context Protocol)는 Claude가 외부 도구·서비스와 표준화된 방식으로 통신할 수 있게 하는 프로토콜입니다. MCP 서버를 추가하면 Claude가 웹을 검색하거나, 특정 폴더를 직접 읽거나, 데이터베이스에 쿼리를 실행하는 등 기본 기능 이상의 작업을 수행할 수 있습니다.

💡 이 장의 범위

MCP 서버 설치 및 설정을 다룹니다. 직접 MCP 서버를 개발하는 내용은 포함하지 않습니다. 연구자에게 유용한 공개 MCP 서버를 중심으로 설명합니다.

1. MCP 동작 원리

MCP는 Claude(클라이언트) — MCP 서버 — 외부 서비스의 3단계 구조로 동작합니다.

Claude Code
⟷
MCP 서버
(로컬 프로세스)
⟷
외부 서비스
(웹, DB, 파일 등)

Claude가 특정 작업(예: 웹 검색)을 요청하면 → MCP 서버가 실제 검색을 수행하고 → 결과를 Claude에게 돌려줍니다. Claude 자체는 인터넷에 직접 접근하지 않으며, MCP 서버가 그 역할을 합니다.

2. 연구자에게 유용한 MCP 서버

📁
Filesystem
@modelcontextprotocol/server-filesystem
지정한 폴더를 Claude가 직접 읽고 쓸 수 있도록 합니다. 대용량 파일 폴더 관리, 자동 파일 정리에 유용.
🌐
Brave Search
@modelcontextprotocol/server-brave-search
Claude가 실시간 웹 검색을 수행합니다. 최신 논문 발표, 학술 뉴스 검색에 활용 가능.
🔍
Web Fetch
@modelcontextprotocol/server-fetch
특정 URL의 내용을 가져옵니다. 학술 저널 페이지, 연구기관 공지 확인 자동화에 유용.
🗄️
SQLite
@modelcontextprotocol/server-sqlite
SQLite 데이터베이스에 쿼리를 실행합니다. 대규모 설문 데이터를 DB로 관리할 때 유용.
📝
Memory
@modelcontextprotocol/server-memory
Claude가 세션 간에도 기억해야 할 정보를 저장합니다. 연구 진행 상황 추적에 활용 가능.
🤔
Sequential Thinking
@modelcontextprotocol/server-sequential-thinking
복잡한 추론이 필요한 작업에서 단계별 사고를 도와줍니다. 연구 설계, 방법론 검토에 유용.

주요 MCP 서버 설치 설정 예시

아래는 자주 쓰는 MCP 서버의 settings.json 설정 블록입니다. Filesystem/Brave Search 외에도 필요한 서버를 mcpServers 객체 안에 추가할 수 있습니다.

Web Fetch MCP — 특정 URL 내용 가져오기

"fetch": {
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-fetch"]
}

API 키 불필요. 설치 후 "이 URL의 내용을 가져와줘"와 같이 바로 사용할 수 있습니다.

SQLite MCP — 연구 데이터 DB 쿼리

"sqlite": {
  "command": "npx",
  "args": [
    "-y",
    "@modelcontextprotocol/server-sqlite",
    "--db-path",
    "/Users/your-username/Desktop/my-research/data/survey.db"
  ]
}

--db-path에 연결할 SQLite 파일 경로를 지정합니다. 설문 데이터를 DB로 관리할 때 유용하며, 연결 후 "respondents 테이블의 행 수를 알려줘" 같은 자연어 쿼리가 가능합니다.

Memory MCP — 세션 간 기억 저장

"memory": {
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-memory"]
}

연구 진행 상황, 변인 정의, 중요 결정 사항을 Claude가 세션을 넘어 기억하게 합니다. 대화 중 "이걸 기억해줘"라고 하면 다음 세션에서도 참조할 수 있습니다.

💡 전체 설정 파일 예시 — 여러 MCP 동시 등록

여러 서버를 함께 등록하려면 mcpServers 객체 안에 나열하면 됩니다.

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/your-username/Desktop/my-research"]
    },
    "brave-search": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-brave-search"],
      "env": { "BRAVE_API_KEY": "여기에_API_키_입력" }
    },
    "fetch": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-fetch"]
    },
    "sqlite": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sqlite", "--db-path", "/Users/your-username/Desktop/my-research/data/survey.db"]
    },
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory"]
    }
  }
}

3. 설정 파일 위치 — Claude Code CLI vs Claude Desktop

이 가이드는 Claude Code CLI(터미널)를 기반으로 합니다. Claude Code CLI와 Claude Desktop 앱은 설정 파일 경로가 다릅니다. 아래 표에서 자신이 사용하는 플랫폼을 확인하세요.

Claude Code CLI (이 가이드) Claude Desktop 앱
Mac 경로 ~/.claude/settings.json ~/Library/Application Support/Claude/
claude_desktop_config.json
Windows 경로 %USERPROFILE%\.claude\settings.json %APPDATA%\Claude\claude_desktop_config.json
JSON 키 "mcpServers": { ... } "mcpServers": { ... } (동일)
재시작 방법 터미널에서 exit 후 claude 재실행 앱 완전 종료 후 재시작
💡 프로젝트별 MCP 설정도 가능

전역 설정(~/.claude/settings.json) 외에도 프로젝트 폴더의 .claude/settings.json에 MCP를 설정할 수 있습니다. 특정 연구 프로젝트에서만 SQLite DB를 연결하고 싶을 때 유용합니다.

4. MCP 서버 설치 방법

  1. Node.js 설치 확인

    대부분의 MCP 서버는 npm 패키지로 배포됩니다. v18 이상 필요.

    node --version  # v18 이상 출력되어야 함
npm --version

  2. 설정 파일 열기 (Claude Code CLI 기준)

    # Mac — 설정 파일 직접 편집
open -e ~/.claude/settings.json

# 파일이 없으면 먼저 생성
mkdir -p ~/.claude
echo '{}' > ~/.claude/settings.json

# Windows PowerShell
notepad "$env:USERPROFILE\.claude\settings.json"

  3. 설정 파일에 MCP 서버 추가

    기존 settings.json에 mcpServers 블록을 추가합니다.

    {
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/your-username/Desktop/my-research"
      ]
    },
    "brave-search": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-brave-search"],
      "env": {
        "BRAVE_API_KEY": "여기에_발급받은_API_키_입력"
      }
    }
  }
}

    다른 설정(hooks 등)이 이미 있다면 해당 JSON 객체 안에 "mcpServers" 키를 추가하세요.

  4. Claude Code 재시작 후 연결 확인

    # 현재 세션 종료
exit

# 새 세션 시작
claude

# MCP 서버 연결 상태 확인 (Claude Code CLI)
/mcp
filesystem: connected
brave-search: connected

    MCP 서버가 connected로 표시되면 정상입니다. error가 표시되면 아래 트러블슈팅을 참고하세요.

5. Filesystem MCP 실전 활용

Filesystem MCP를 연결하면 Claude가 지정한 폴더의 파일을 직접 읽고 수정할 수 있습니다. 매번 파일을 붙여넣지 않아도 됩니다.

✍️ 프롬프트 예시 — 파일 목록 확인

01_literature 폴더에 어떤 파일들이 있는지 목록을 보여줘. PDF 파일 제목과 파일 크기도 포함해서.

✍️ 프롬프트 예시 — 자동 요약

01_literature 폴더에 있는 모든 .md 파일을 읽고 각 논문의 연구방법(1-2줄)을 정리한 표를 만들어줘.

⚠️ 보안 주의

Filesystem MCP는 지정한 폴더 내 모든 파일에 읽기/쓰기 접근이 가능합니다. 개인정보가 포함된 원시 데이터 폴더는 MCP 접근 범위에서 제외하거나, 연구 프로젝트 폴더만 최소한으로 지정하세요. 경로를 여러 개 지정하려면 args에 경로를 추가하면 됩니다.

6. Brave Search API 키 발급 — 단계별 가이드

Brave Search MCP를 사용하려면 API 키가 필요합니다. 무료 플랜에서 월 2,000회 검색이 제공되며, 신용카드 없이 가입할 수 있습니다.

  1. Brave Search API 사이트 접속

    브라우저에서 api.search.brave.com에 접속합니다.

  2. 계정 생성

    "Get Started for Free" 버튼 클릭 → 이메일/소셜 계정으로 가입 → 이메일 인증 완료.

  3. API 키 생성

    로그인 후 대시보드 왼쪽 메뉴 → "API Keys" → "Create New Key" 클릭
    이름 입력(예: "claude-research") → 생성 완료 후 키 복사

    # 무료 플랜 한도: 월 2,000회 검색
# 초과 시: $5/1,000회 유료 결제 (연구자 기준 거의 초과 안 됨)

  4. settings.json에 키 입력

    위 설정 파일의 "BRAVE_API_KEY" 값에 복사한 키를 붙여넣습니다. Claude를 재시작하면 적용됩니다.

7. 트러블슈팅 — MCP 연결 오류

오류 메시지원인해결 방법
command not found: npx Node.js 미설치 또는 PATH 미등록 node --version 확인 후 재설치. 설치 가이드 참조
error: permission denied 설정한 폴더 경로 접근 권한 없음 폴더 경로 재확인. Mac: 시스템 설정 → 개인정보 보호 → 파일 접근 허용
API key invalid Brave Search API 키 오류 키 앞뒤 공백 제거, 따옴표 올바른지 확인
연결은 됐는데 동작 안 함 MCP 서버 프로세스 오류 claude --mcp-debug로 실행해 오류 로그 확인
✅ 이 장을 마쳤다면

~/.claude/settings.json의 mcpServers 블록에 Filesystem MCP를 추가하고 /mcp 명령으로 연결 상태를 확인하는 방법을 알고 있어야 합니다. Claude Code CLI와 Claude Desktop 앱의 설정 파일 경로가 다르다는 것도 기억하세요.

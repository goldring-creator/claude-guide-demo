처음 실행할 때는 논문 3~10편만 넣어 결과가 올바른지 확인하세요. 전체 50편은 품질 확인 후 처리합니다.

4
classify.py 작성 코드 복사

아래 코드를 복사해 classify.py로 저장합니다. 분류 기준(CATEGORIES)은 연구 주제에 맞게 수정하세요.

from dotenv import load_dotenv
import anthropic
import pandas as pd
import time

# ──────────────────────────────────────────────────
# 여기를 수정하세요 — 연구 주제에 맞는 분류 기준
CATEGORIES = [
    "교수법",       # 수업 방법, 교수 전략
    "교육과정",     # 교육과정 설계, 재구성
    "교육평가",     # 평가 방법, 학업 성취 측정
    "교사교육",     # 교사 전문성, 연수
    "학습동기",     # 자기효능감, 내재적 동기
    "특수교육",     # 장애, 통합교육
    "교육정책",     # 제도, 법령, 행정
    "기타"          # 위 범주에 해당하지 않는 경우
]
INPUT_FILE  = "papers.csv"     # 입력 파일명
OUTPUT_FILE = "results.csv"    # 결과 파일명
TITLE_COL   = "title"          # 제목 열 이름
ABSTRACT_COL = "abstract"      # 초록 열 이름
# ──────────────────────────────────────────────────

load_dotenv()
client = anthropic.Anthropic()

def classify_paper(title: str, abstract: str) -> str:
    """논문 주제를 분류합니다. 분류 결과 하나만 반환합니다."""
    categories_str = ", ".join(CATEGORIES)
    response = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=30,
        messages=[{
            "role": "user",
            "content": (
                f"다음 논문의 연구 주제를 아래 분류 중 하나로만 답하세요.\n"
                f"분류: {categories_str}\n\n"
                f"제목: {title}\n"
                f"초록: {abstract[:400]}\n\n"
                f"분류 결과(하나만):"
            )
        }]
    )
    result = response.content[0].text.strip()
    return result if result in CATEGORIES else "기타"

# CSV 읽기
df = pd.read_csv(INPUT_FILE)
print(f"총 {len(df)}편 처리 시작\n")

results = []
errors  = []

for i, row in df.iterrows():
    title_preview = str(row[TITLE_COL])[:35]
    print(f"[{i+1:3}/{len(df)}] {title_preview}...", end=" ")
    try:
        category = classify_paper(str(row[TITLE_COL]), str(row[ABSTRACT_COL]))
        results.append(category)
        print(f"→ {category}")
    except Exception as e:
        results.append("오류")
        errors.append((i, str(e)))
        print(f"→ 오류: {e}")
    time.sleep(0.3)   # 호출 간격

# 결과 저장
df["category"] = results
df.to_csv(OUTPUT_FILE, index=False, encoding="utf-8-sig")

print(f"\n완료! {OUTPUT_FILE} 저장됨")
print(f"오류 건수: {len(errors)}")
if errors:
    for idx, msg in errors:
        print(f"  행 {idx}: {msg}")
💡 분류 기준 수정 방법

코드 상단의 CATEGORIES 목록을 연구 목적에 맞게 바꾸세요. 예를 들어 메타분석 연구라면 ["무선통제실험", "준실험설계", "단일사례", "질적연구", "혼합방법", "문헌고찰"]처럼 연구 설계 유형으로 분류할 수도 있습니다.

비용 추정

Haiku 모델 기준, 논문 1편 처리에 사용되는 토큰은 대략 다음과 같습니다.

항목토큰 수(편당 평균)내용
입력 토큰약 200~300 토큰프롬프트 + 제목 + 초록 앞 400자
출력 토큰약 5~10 토큰분류 결과 한 단어
50편 합산약 15,000~16,000 토큰
💡 비용은 $0.05 미만

Haiku는 매우 저렴해서 논문 50편 분류에 $0.01~0.05 정도면 충분합니다. 정확한 요금은 anthropic.com/pricing에서 확인하세요.

문제원인해결 방법
AuthenticationError API 키 오류 또는 .env 파일 위치가 다름 .env가 classify.py와 같은 폴더에 있는지 확인. 키 앞뒤 공백 제거
ModuleNotFoundError 라이브러리 미설치 pip3 install anthropic pandas python-dotenv 재실행
분류 결과가 모두 "기타" Claude 응답이 CATEGORIES 목록과 정확히 일치하지 않음 프롬프트에 "반드시 목록 중 하나로만 답하세요"를 더 강조하거나, 응답 후처리 로직을 추가
한글 CSV 깨짐 인코딩 문제 pd.read_csv("papers.csv", encoding="utf-8-sig") 또는 encoding="cp949" 시도
KeyError: 'title' CSV 열 이름이 다름 코드 상단의 TITLE_COL을 실제 열 이름으로 수정

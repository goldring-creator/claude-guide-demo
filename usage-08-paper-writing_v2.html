논문작성 실전

활용 08  v2  서론부터 참고문헌까지 — 장별 작성 전략과 프롬프트 (범용 버전 + 심사 대응 편지 예시 추가)

이 장에서는 논문의 각 장(Chapter)을 Claude와 함께 작성하는 구체적인 방법을 다룹니다. 각 장마다 고유한 목적과 구조가 있으므로, 그에 맞는 프롬프트 전략을 소개합니다. 프롬프트의 [대괄호] 부분은 자신의 연구에 맞게 바꾸세요.

💡 논문 작성의 황금 원칙

Claude는 초안 생성기, 연구자는 편집자. Claude가 생성한 텍스트를 그대로 사용하면 학술적 목소리가 사라집니다. Claude의 초안에서 아이디어와 구조를 가져오되, 문장 수준에서 연구자의 언어로 재작성하는 과정이 반드시 필요합니다.

1. 장별 작성 가이드

1장. 서론 (Introduction)
깔때기 구조

서론은 넓은 맥락 → 문제 좁히기 → 연구의 필요성 → 연구 목적 → 논문 구성의 깔때기 구조로 작성합니다.

✍️ 서론 초안 작성 프롬프트

내 연구([연구 주제 및 연구방법])의 서론을 써줘. 다음 구조로:
1. [연구 문제/현상]의 현황 (관련 통계 포함, 최근 5년 내 데이터 우선)
2. 기존 연구의 한계 (방법론적 한계, 대상 집단 또는 맥락의 공백)
3. 본 연구의 필요성과 차별성 ([연구방법] 활용, [데이터/맥락])
4. 연구 목적 3가지 (번호 목록)
5. 논문 구성 안내 (1-2문장)
분량 1,200-1,500자, APA 인용 형식. 04_writing/ch1_intro.md에 저장.

서론 완성 후 검토 포인트:

  • 첫 문단이 독자의 관심을 끄는가? (충격적 통계, 핵심 문제 제기)
  • 연구 공백이 명확하게 드러나는가?
  • 연구 목적이 구체적이고 측정 가능한가?
2장. 이론적 배경 (Literature Review)
문헌 종합

이론적 배경은 단순 나열이 아닌 내 연구를 지지하는 이론적 틀 구축입니다. 각 섹션이 연구 목적과 연결되어야 합니다.

✍️ 이론적 배경 섹션 작성 프롬프트

2장 1절 "[핵심 이론명]"을 써줘. 03_analysis/literature_summary.md 의 관련 논문들을 참고해서:
- [핵심 이론가/저자(연도)]의 이론 핵심 설명
- [연구 주요 변인]의 유형과 선행연구 현황
- [조절·매개 변인]의 역할 및 연구 현황
- 소절 마지막에 본 연구와의 연결 문장
분량 1,000-1,200자. 04_writing/ch2_theory.md에 저장.

💡 문헌고찰 작성 Skill 활용

academic-writing 스킬을 함께 사용하면 학술적 문헌 종합 방식을 안내받을 수 있습니다.

3장. 연구방법 (Methodology)
재현 가능성

연구방법은 다른 연구자가 동일 방법으로 재현할 수 있을 만큼 구체적으로 작성해야 합니다.

소절포함 내용
연구 설계연구 유형, 연구 목적과 방법의 적합성
연구 참여자표본 크기, 표집 방법, 인구통계적 특성 표
측정 도구각 변인의 척도, 문항 수, 신뢰도 계수
분석 방법사용한 통계 방법, 프로그램, 분석 순서
연구 윤리IRB 승인, 동의 절차, 데이터 보안
✍️ 연구방법 작성 프롬프트

3장 "측정 도구" 소절을 써줘. 내 연구에서 사용한 척도:
- [변인명 1]: [문항 수]문항, [척도 유형 — 예: 5점 리커트]
- [변인명 2]: [문항 수]문항, [척도 유형]
- 각 척도의 출처, Cronbach α, 본 연구 α 포함
- 분량 800자, APA 인용. 04_writing/ch3_measures.md 저장.

4장. 결과 (Results)
사실 기술

결과 섹션은 해석 없이 사실만 기술합니다. 통계치를 APA 형식으로 정확하게 보고합니다.

✍️ 결과 작성 프롬프트 — 기술통계

03_analysis/descriptive_results.csv 파일을 읽고 4장 1절 "기술통계 및 상관분석" 결과를 써줘. APA 형식으로:
- 주요 변인의 평균, 표준편차 기술
- 상관계수 표 (Table 1) — 유의수준 * p < .05, ** p < .01 표시
- 결과 서술 300-400자
04_writing/ch4_descriptive.md 저장.

✍️ 결과 작성 프롬프트 — 주요 분석

03_analysis/main_results.csv 파일을 읽고 4장 2절 "[주요 분석방법] 결과"를 써줘:
- 분석 모형 결정 과정 (적합도 지수 표 포함)
- 최종 결과 특성 서술 (각 집단/요인 명명 포함)
- 결과 분포 표
- 그래프 설명 텍스트 (Figure 1)
분량 800-1000자. 04_writing/ch4_main.md 저장.

APA 통계 보고 형식 예시:

  • t검정: t(298) = 3.42, p = .001, d = 0.39
  • F검정: F(2, 297) = 8.71, p < .001, η² = .06
  • 회귀: β = .34, SE = .08, p < .001
  • 상관: r(299) = .52, p < .001
5장. 논의 (Discussion)
해석과 의미

논의는 결과의 의미를 해석하고, 선행연구와 연결하고, 연구의 기여와 한계를 제시하는 장입니다.

✍️ 논의 작성 프롬프트

5장 논의를 써줘. 04_writing/ch4_main.md 의 결과와 03_analysis/literature_summary.md 의 선행연구를 참고해서:
1. 주요 결과 각각의 의미 해석 (선행연구와 비교)
2. [핵심 이론] 관점에서의 해석
3. 연구의 이론적 기여 2가지
4. 실천적 시사점 3가지 ([이해관계자 1], [이해관계자 2], [이해관계자 3])
5. 연구 한계 및 후속 연구 방향
분량 2,000-2,500자, APA 인용. 04_writing/ch5_discussion.md 저장.

초록 (Abstract)
논문 완성 후

초록은 논문 완성 후 마지막으로 작성합니다. 전체 논문을 요약하므로, 모든 장이 완성된 후에 쓰세요.

✍️ 초록 작성 프롬프트

완성된 논문(04_writing/ 폴더의 모든 파일)을 읽고 한국어 초록을 써줘:
- 연구 목적, 연구방법, 주요 결과 3가지, 결론 순서
- 600자 이내
- 키워드 5개 (가나다 순)
그 다음 영문 초록도 작성해줘 (250 words 이내, 같은 구조).
04_writing/abstract.md 에 저장.

참고문헌 (References)
APA 7판

참고문헌은 논문 본문에서 인용한 모든 자료를 APA 7판 형식으로 정렬합니다.

✍️ 참고문헌 생성 프롬프트

04_writing/ 폴더의 모든 파일에서 인용된 참고문헌을 수집하고, 01_literature/references.bib 을 참조해서 APA 7판 형식 참고문헌 목록을 만들어줘. 한국어 문헌 가나다 순 먼저, 영어 알파벳 순 다음. 04_writing/references.md 에 저장.

⚠️ 참고문헌 필수 확인

Claude가 생성한 참고문헌 목록에서 본문에 인용되지 않은 항목, 존재하지 않는 논문, 형식 오류를 반드시 확인하세요. 최소 10% 이상 무작위 샘플링해서 원문과 대조합니다.

심사 의견 유형별 대응 전략

의견을 받았을 때 수용·수정·반박 중 어떤 방향을 선택할지 기준이 필요합니다.

유형 대표 사례 권장 대응 Claude 활용
방법론 지적 "표본 크기가 부족하다", "통제변수 누락" 가능하면 수용·보완. 불가하면 한계로 명시 추가 분석 코드 작성, 민감도 분석 제안
해석 이견 "결과 해석이 과도하다", "대안 설명 미제시" 근거 보강 또는 대안 해석 병기 반론 논거 탐색, 논의 단락 보강 초안
문체·형식 교정 "표 형식이 맞지 않는다", "초록이 너무 길다" 전면 수용·수정 해당 섹션 직접 수정
추가 문헌 요구 "최근 연구가 인용되지 않았다" 제시된 문헌 검토 후 인용 여부 판단 관련 문헌 요약, 인용 문장 초안

심사 대응 편지 예시

수정 원고 제출 시 심사위원에게 보내는 대응 편지(Response Letter)의 구조와 실제 예시입니다. 각 의견에 대해 감사 → 의견 요약 → 대응 방향 → 수정 내용 및 페이지 순으로 작성합니다.

대응 편지 구조 예시 — 방법론 지적 수용의 경우

심사위원 선생님께

귀중한 검토 의견 주셔서 깊이 감사드립니다. 선생님의 지적을 반영하여 다음과 같이 수정하였습니다.

의견 1

"표본이 단일 지역에 한정되어 결과의 일반화 가능성이 제한된다."

심사위원 선생님의 의견이 타당합니다. 본 연구의 표본이 [지역/기관]에 한정된 것은 사실입니다. 이를 제한점으로 명확히 기술하였으며, 수정 원고 [p. X]의 제한점 섹션에 아래 내용을 추가하였습니다.

"본 연구의 표본은 [지역]에 한정되어 있어 결과를 다른 지역 또는 문화적 맥락으로 일반화할 때 주의가 필요하다. 향후 연구에서는 다지역 표본을 통한 검증이 필요하다."

의견 2

"논의 섹션에서 대안적 해석이 충분히 다뤄지지 않았다."

지적하신 바와 같이 대안적 해석이 부족하였습니다. 수정 원고 [p. X]에 다음 단락을 추가하였습니다.

"그러나 이러한 결과는 [대안적 해석 내용]으로도 설명될 수 있다. 향후 연구에서 이 가능성을 보다 엄밀하게 검증할 필요가 있다."

이상의 수정이 미흡하다면 추가 의견 주시면 반영하겠습니다. 다시 한번 감사드립니다.

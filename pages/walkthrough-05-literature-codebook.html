프롬프트

나는 "[예: 교사 AI 리터러시]"를 주제로 문헌 검토를 진행 중입니다.

논문 코드북에 포함할 추출 항목을 추천해 주세요. 교육학 연구에서 일반적으로 사용하는 항목을 기준으로, 이 주제에 특화된 항목을 추가해서 총 12~15개 항목의 코드북 설계를 제안해 주세요. CSV 헤더 형식으로 제공해 주세요.

논문 텍스트 공유 및 정보 추출Claude

Claude Code에서 PDF 파일을 @파일명.pdf 또는 @폴더명/으로 공유하거나, claude.ai에서 파일을 첨부합니다. PDF를 공유할 수 없다면 초록+방법+결과 섹션 텍스트를 직접 붙여넣어도 됩니다.

프롬프트 (논문 1편씩 처리)

아래 논문에서 다음 항목들을 추출해 주세요. 항목이 논문에 명시되지 않은 경우 "NA"로 표기하고, 불명확한 경우 "?"를 붙여주세요.

추출 항목: 저자, 발행연도, 학술지명, 국가, 연구설계, 연구대상, 표본크기, 측정도구, 주요변수, 분석방법, 주요결과, 효과크기

결과는 CSV 한 행 형식으로 제공해 주세요.

3
오류 검토 및 불일치 확인연구자

CSV를 Excel로 열어 직접 확인합니다. 특히 효과크기, 표본크기, 연구설계 분류에 오류가 있을 수 있습니다.

💡 검토 포인트

- 표본크기: 원논문과 대조 (Claude가 간혹 부표본과 혼동)
- 효과크기: β값과 r값을 혼동하는 경우 있음
- 연구설계: 질적/양적 분류 확인
- NA 항목: 직접 논문을 보고 채울 수 있는지 확인

4
코드북 기반 문헌 패턴 분석Claude

코드북이 완성되면 전체 문헌의 패턴을 분석하고 문헌고찰 섹션 작성을 돕습니다.

프롬프트

아래 코드북 CSV를 바탕으로 문헌 패턴 분석을 해주세요:

1. 연구설계 유형 분포 (양적/질적/혼합 비율)
2. 연도별 연구 추이 (어느 시점부터 증가했는지)
3. 주로 사용된 분석 방법 Top 3
4. 표본 크기 분포 (중앙값, 범위)
5. 연구 공백으로 보이는 영역

완료 체크리스트

  • 10편 이상의 논문에서 정보가 추출됨
  • CSV 코드북의 각 셀을 직접 검토하여 오류 수정됨
  • 코드북을 Excel에서 열어 정렬·필터 기능으로 패턴 확인됨
  • 연구 공백 영역 2개 이상 파악됨
  • 문헌고찰 섹션 서술 방향이 결정됨

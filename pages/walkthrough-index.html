실전 워크스루 시리즈

따라하기

설문지 제작부터 HLM 분석까지 — 실제 연구 상황을 단계별로 따라하며 Claude 활용법을 익힙니다.
각 실습은 가이드 본문 내용을 숙지한 상태를 전제로 하며, 관련 파트 링크가 함께 제공됩니다.

이 섹션을 활용하는 법

1
난이도 확인
초급은 터미널·코딩 경험이 없어도 따라할 수 있습니다. 중급은 Claude Code 기본 조작이 가능한 수준, 고급은 R·통계 배경이 있는 수준을 전제합니다.
2
준비물 확인
각 실습 페이지에는 '준비물' 섹션이 있습니다. 실제 파일(데이터, 전사본 등)이 있으면 그대로 써도 되고, 예시 텍스트를 임시로 사용해도 됩니다.
3
프롬프트 복사
파란 박스 안의 프롬프트는 Claude에 그대로 붙여넣어 사용할 수 있습니다. 꺾쇠 괄호 [이곳]은 본인 내용으로 바꾸세요.
4
가이드와 함께 보기
각 단계에서 관련 가이드 링크가 표시됩니다. 개념이 헷갈리면 해당 가이드 페이지로 이동해 확인하고 돌아오세요.
💡 권장 학습 경로

처음이라면 — 입문 파트 전체 + 활용 01~02를 먼저 읽은 뒤 초급 실습부터 시작하세요.
특정 분석이 급하다면 — 난이도와 주제를 보고 바로 해당 실습으로 이동해도 됩니다.

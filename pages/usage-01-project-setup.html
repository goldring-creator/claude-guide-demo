연구 프로젝트 세팅

활용 01  폴더 구조 설계, Claude Code 시작, CLAUDE.md 작성

Claude Code를 설치했다면 이제 실제 연구에 투입할 차례입니다. 이 장에서는 연구 프로젝트를 Claude와 함께 시작하는 표준 절차를 다룹니다. 폴더 구조를 어떻게 잡아야 Claude가 잘 작동하는지, CLAUDE.md는 어떻게 작성해야 하는지 구체적으로 안내합니다.

1. 왜 폴더 구조가 중요한가

Claude Code는 현재 작업 폴더를 기준으로 모든 것을 읽고 씁니다. 논문 초안, 인터뷰 녹취록, R 분석 코드, 참고문헌 파일이 모두 같은 폴더 안에 있으면 Claude가 맥락을 파악하고 파일 간 연결을 자동으로 처리합니다.

반대로 파일이 바탕화면, 다운로드 폴더, USB 드라이브에 흩어져 있으면 "이 논문에서 사용한 인터뷰 자료 기반으로 3장 논의를 보완해줘" 같은 복합 작업이 어려워집니다.

💡 기본 원칙

논문 한 편 = 폴더 하나. 그 폴더 안에서 Claude를 시작하세요. 모든 관련 파일(문헌, 데이터, 원고, 분석 코드)을 이 폴더 안에 넣어두면 Claude가 전체 맥락을 파악할 수 있습니다.

2. 권장 폴더 구조

아래는 교육학 연구자를 위한 기본 폴더 구조입니다. 연구 유형(문헌연구, 양적, 질적)에 따라 일부 폴더는 필요 없을 수 있습니다.

my-research/ ← 프로젝트 최상위 폴더 │ ├── CLAUDE.md ← Claude 지시사항 (아래에서 작성법 설명) │ ├── 01_literature/ ← 수집한 논문 PDF │ ├── kim2023_teacher_burnout.pdf │ ├── lee2022_job_demands.pdf │ └── references.bib ← BibTeX 참고문헌 파일 │ ├── 02_data/ ← 원시 데이터 (절대 수정 금지) │ ├── survey_raw.csv │ └── interview_transcripts/ │ ├── participant_01.txt │ └── participant_02.txt │ ├── 03_analysis/ ← 분석 코드 및 결과 │ ├── analysis.R ← R 분석 스크립트 │ ├── results_table1.csv │ └── figures/ │ └── fig1_lpa_profiles.png │ ├── 04_writing/ ← 논문 초안 │ ├── draft_intro.md │ ├── draft_method.md │ └── draft_full.docx │ └── 05_notes/ ← 메모, 아이디어, 회의록 └── research_memo.md
💡 번호 접두사의 장점

폴더 이름 앞에 01_, 02_처럼 번호를 붙이면 파인더/탐색기에서 항상 순서대로 정렬됩니다. Claude도 파일 목록을 볼 때 논리적 흐름을 더 잘 파악합니다.

폴더 생성 방법

Finder(Mac) 또는 탐색기(Windows)에서 직접 만드는 방법이 가장 쉽습니다. 터미널에 익숙하다면 한 번에 만들 수도 있습니다.

방법 A — Finder에서 직접 만들기 (권장)

  1. 바탕화면에서 오른쪽 클릭 → 새 폴더를 선택합니다.
  2. 폴더 이름을 my-research로 짓습니다.
  3. 그 안에 01_literature, 02_data, 03_analysis, 04_writing, 05_notes 폴더를 차례로 만듭니다.
터미널에 익숙하다면 — 명령어로 한 번에 만들기

터미널을 열고 아래 명령어를 실행합니다. my-research는 원하는 이름으로 바꾸세요.

# 바탕화면에 프로젝트 폴더 생성
cd ~/Desktop
mkdir -p my-research/{01_literature,02_data/interview_transcripts,03_analysis/figures,04_writing,05_notes}

# 잘 만들어졌는지 확인
ls my-research/

방법 A — 탐색기에서 직접 만들기 (권장)

  1. 바탕화면에서 오른쪽 클릭 → 새로 만들기 → 폴더를 선택합니다.
  2. 폴더 이름을 my-research로 짓습니다.
  3. 그 안에 01_literature, 02_data, 03_analysis, 04_writing, 05_notes 폴더를 차례로 만듭니다.
터미널에 익숙하다면 — 명령어로 한 번에 만들기

PowerShell을 열고 아래 명령어를 실행합니다.

# 바탕화면에 프로젝트 폴더 생성
cd $HOME\Desktop
mkdir my-research, my-research\01_literature, my-research\02_data, my-research\02_data\interview_transcripts, my-research\03_analysis, my-research\03_analysis\figures, my-research\04_writing, my-research\05_notes

# 잘 만들어졌는지 확인
dir my-research

3. Claude Code 시작하기

Claude Code를 사용할 때 가장 중요한 규칙은 하나입니다: 반드시 프로젝트 폴더 안에서 시작하세요.

  1. 터미널에서 프로젝트 폴더로 이동

    # 바탕화면의 my-research 폴더로 이동
cd ~/Desktop/my-research

# 현재 위치 확인
pwd
/Users/username/Desktop/my-research

    Finder에서 폴더를 열고 Control+클릭 → "폴더에서 터미널 열기"를 선택해도 됩니다.

    # 바탕화면의 my-research 폴더로 이동
cd $HOME\Desktop\my-research

# 현재 위치 확인
pwd
C:\Users\username\Desktop\my-research

    탐색기에서 폴더를 열고 주소 표시줄에 powershell을 입력 후 Enter를 눌러도 됩니다.

  2. Claude Code 실행

    claude

    잠시 후 Claude가 시작되면서 아래와 같은 프롬프트가 나타납니다.

    ~/Desktop/my-research
    Claude Code v1.x.x | /help for commands ✓ Working directory: /Users/username/Desktop/my-research > 이 폴더에서 시작할게요. 어떤 작업을 도와드릴까요? > _

  3. 폴더 상황을 Claude에게 먼저 파악시키기

    처음 시작했을 때, 현재 연구 폴더가 어떤 상태인지 Claude에게 먼저 알려주면 이후 작업이 훨씬 빨라집니다.

    ✍️ 프롬프트 예시

    이 폴더는 교사 직무요구와 소진에 관한 양적 연구 프로젝트야. 01_literature 폴더에 수집한 논문 PDF가 있고, 02_data에 TALIS 2024 설문 데이터가 있어. 지금 2장 연구방법 작성 단계야. 폴더 구조 파악하고 시작해줘.

    📋 Claude 응답 예시

    폴더 구조를 확인했습니다. 현재 상태:
    — 01_literature: PDF 12개
    — 02_data: survey_raw.csv (n=3,500), interview_transcripts 없음
    — 04_writing: draft_intro.md (2,400자)

    연구방법 작성을 위해 어떤 분석 방법을 사용하셨나요? (예: 회귀분석, 구조방정식, LPA 등)

⚠️ 자주 하는 실수

프로젝트 폴더가 아닌 홈 디렉토리(~)나 바탕화면 루트에서 Claude를 시작하면, Claude가 수백 개의 무관한 파일을 볼 수 있어 혼란이 생깁니다. 반드시 해당 프로젝트 폴더 안으로 이동한 후 claude를 실행하세요.

4. CLAUDE.md — Claude에게 주는 연구 지침서

CLAUDE.md는 프로젝트 폴더 최상위에 두는 텍스트 파일입니다. Claude Code를 시작할 때 자동으로 읽히기 때문에, 매번 같은 설명을 반복하지 않아도 됩니다.

🧠
Claude의 장기 기억
대화를 새로 시작해도 CLAUDE.md에 적힌 내용은 항상 기억됩니다. 연구 맥락, 선호 문체, 자주 쓰는 명령어를 여기에 적어두세요.
📋
프로젝트 안내서
이 폴더가 어떤 연구인지, 데이터는 어디 있는지, 어떤 파일을 건드리면 안 되는지 적어두면 Claude가 실수를 줄입니다.
✍️
문체·형식 지정
APA 7판 사용, 3인칭 서술, 수동태 지양 등 논문 작성 규칙을 지정하면 일관된 문체로 작업합니다.

CLAUDE.md 작성 방법

CLAUDE.md는 일반 텍스트(마크다운 형식)로 작성합니다. 아래 템플릿을 복사해서 내 연구에 맞게 수정하세요.

CLAUDE.md — 연구자용 기본 템플릿
# 연구 프로젝트 지침 ## 연구 개요 - 연구 제목: 교사의 직무요구가 소진에 미치는 영향: 잠재프로파일분석 - 연구자: 홍길동 (○○대학교 교육학 박사과정) - 현재 단계: 2장 연구방법 작성 중 - 목표 학술지: 교육학연구 (KCI 등재지) - 데이터: TALIS 2024 한국 교사 표본 (n=3,500) ## 폴더 구조 - 01_literature/: 수집한 논문 PDF 및 BibTeX 파일 - 02_data/: 원시 데이터 (절대 수정하지 말 것) - 03_analysis/: R 분석 코드 및 결과 - 04_writing/: 논문 초안 (마크다운 파일) - 05_notes/: 메모 및 아이디어 ## 작업 규칙 - 절대 수정 금지: 02_data/ 폴더 내 모든 파일 (원시 데이터 보존) - 분석 결과는 반드시 03_analysis/에 저장 - 작업 전 현재 파일 구조를 먼저 파악하고 시작할 것 ## 논문 작성 스타일 - 인용 형식: APA 7판 - 서술 방식: 3인칭, 학술 문체 - 수동태: 가급적 지양 (능동태 선호) - 문단 길이: 4~8문장 권장 - 출력 형식: 마크다운 (.md) ## 분석 환경 - 통계 프로그램: R 4.3.x - 주요 패키지: tidyverse, lavaan, mclust, lme4 - 분석 방법: LPA (잠재프로파일분석), 다층모형 ## 연구 핵심 변인 - 독립변수: 직무요구 (시간압박, 행정부담, 학생행동문제) - 종속변수: 교사 소진 (정서적 탈진, 비개인화, 성취감 저하) - 조절변수: 직업적 효능감 ## 참고 이 파일은 Claude Code가 자동으로 읽습니다. 연구 진행에 따라 "현재 단계" 항목을 업데이트하세요.
💡 CLAUDE.md 파일 만들기

Claude Code 안에서 직접 만들 수도 있습니다:

CLAUDE.md 파일을 만들어줘. 이 연구는 [연구 주제]에 관한 [연구 방법] 연구야. 데이터는 02_data 폴더에 있고, APA 7판 형식을 사용해.

CLAUDE.md를 학습 루프로 활용하기

CLAUDE.md는 단순한 설정 파일을 넘어 실수 기록장이자 학습 루프로 사용할 수 있습니다. Claude는 새 세션을 열 때마다 기억이 초기화됩니다. 하지만 CLAUDE.md에 기록된 내용은 항상 살아남습니다. 같은 실수가 반복되지 않으려면 발생한 실수를 CLAUDE.md에 적어두세요.

💡 실수를 기록하면 실수가 사라집니다

작업 중 Claude가 실수를 했다면 세션 종료 전에 이렇게 요청하세요:

방금 [실수 내용]이 있었어. CLAUDE.md의 '하지 말 것' 섹션에 이 패턴을 기록해줘.

다음 세션에서 Claude가 CLAUDE.md를 읽으면, 같은 실수 없이 바로 작업을 이어갑니다. 세션이 쌓일수록 Claude는 나에게 최적화됩니다.

아래처럼 CLAUDE.md에 ## 하지 말 것 섹션을 추가해두면 학습 루프가 자동으로 돌아갑니다.

CLAUDE.md — 학습 루프 섹션 추가 예시
## 하지 말 것 (학습 루프) # 세션에서 발생한 실수를 여기에 기록합니다 - 2026-04-10: 02_data/ 원시 파일을 직접 수정하려 함 → 절대 금지 - 2026-04-15: 회귀계수를 표준화 없이 비교 → 반드시 표준화 후 비교 - 2026-04-20: 참고문헌 저자 이름을 추측으로 작성 → 원문 확인 후 기재 ## 이번 세션 성공 기준 # 시작 전 성공 기준을 먼저 적어두면 검증이 명확해집니다 - 2장 연구방법 '측정변인' 섹션 600자 이상 작성 완료 - CFA 요인부하량 표 생성 (기준: 모든 부하량 .50 이상)
🔄 검증 루프 — 성공 기준을 먼저 정하세요

작업을 맡기기 전에 성공 기준을 먼저 알려주면 Claude가 스스로 결과를 검증하고 통과되면 완료, 안 되면 재시도합니다. 사람이 일일이 확인하지 않아도 품질이 올라가는 구조입니다.

2장 측정변인 섹션을 써줘. 완료 기준: ① 600자 이상, ② 모든 변인에 출처 인용, ③ APA 7판 형식. 작성 후 스스로 기준을 충족하는지 체크하고 알려줘.

5. 연구 세션 시작 루틴

매일 연구를 시작할 때 아래 루틴을 따르면 Claude와 빠르게 호흡을 맞출 수 있습니다.

  1. 터미널 열고 프로젝트 폴더로 이동

    cd ~/Desktop/my-research
    💡 my-research 부분은 본인 폴더 이름으로 바꾸세요. 바탕화면 외 다른 위치라면 경로 전체를 수정합니다. 
    cd $HOME\Desktop\my-research
    💡 my-research 부분은 본인 폴더 이름으로 바꾸세요. 다른 드라이브라면 cd C:\Users\사용자명\Documents\my-research 형태로 작성합니다.

  2. Claude Code 시작

    claude

    Claude가 자동으로 CLAUDE.md를 읽고 프로젝트 맥락을 파악합니다.

  3. 오늘 작업 목표 전달

    ✍️ 세션 시작 프롬프트 예시

    오늘은 2장 연구방법 중 '측정변인' 섹션을 써야 해. 어제 분석 결과로 confirmatory factor analysis를 완료했고 결과 파일은 03_analysis/cfa_results.csv야. 거기서 요인부하량 표를 만들고 설명 문단 써줘.

  4. CLAUDE.md 업데이트 (필요 시)

    장이 완료되거나 분석 방법이 바뀌면 CLAUDE.md의 "현재 단계" 항목을 업데이트하세요.

    ✍️ 프롬프트 예시

    CLAUDE.md에서 "현재 단계"를 "3장 결과 작성 중 (2장 완료)"으로 업데이트해줘.

6. MCP 기본 연결 — 외부 서비스 연동 (선택)

MCP(Model Context Protocol)를 사용하면 Claude가 직접 외부 서비스에 접근할 수 있습니다. 기초 연구 작업에는 필수가 아니지만, 아래 두 가지는 연구자에게 특히 유용합니다.

MCP 서비스 기능 유용한 상황
Brave Search Claude가 직접 웹 검색 최신 논문 동향 파악, 학술지 정보 확인
Filesystem MCP 지정 폴더 외 다른 폴더도 접근 허용 여러 프로젝트 간 파일 이동·비교
Zotero MCP Zotero 라이브러리에서 직접 참고문헌 가져오기 인용 자동 삽입, 참고문헌 목록 생성
Notion MCP Notion 페이지 읽기/쓰기 연구 노트를 Notion과 동기화
💡 MCP 설정은 고급 파트에서

MCP 연결 설정은 고급 04 — MCP 고급 설정에서 단계별로 안내합니다. 처음에는 MCP 없이도 충분히 작업할 수 있습니다.

7. 자주 묻는 질문

질문 답변
CLAUDE.md 없이도 작동하나요? 작동합니다. 하지만 매번 프로젝트 맥락을 설명해야 합니다. 5분 투자해 CLAUDE.md를 만들어 두면 이후 시간을 크게 절약합니다.
한글 파일명을 사용해도 되나요? Mac에서는 대부분 문제없이 작동합니다. Windows에서는 간혹 인코딩 오류가 날 수 있어 영어+숫자+언더스코어(_) 조합을 권장합니다.
데이터 파일이 너무 크면 어떻게 되나요? 수십 MB 이상의 CSV/Excel 파일은 직접 읽히지 않을 수 있습니다. 대신 파일 경로를 알려주면 Claude가 R/Python 코드를 작성해서 분석합니다.
여러 논문을 동시에 진행 중입니다. 논문마다 별도 폴더를 만들고, 각각의 폴더에 CLAUDE.md를 두세요. Claude Code를 실행할 때 해당 폴더에서 시작하면 됩니다.
Claude가 실수로 파일을 수정했습니다. 원시 데이터는 02_data/ 폴더에만 두고 CLAUDE.md에 "수정 금지" 명시를 해두세요. 또는 해당 폴더를 읽기 전용으로 설정해두면 확실합니다.
cd 없이 그냥 claude를 실행하면 어떻게 되나요? 홈 디렉토리(~) 또는 현재 있는 폴더에서 시작합니다. 프로젝트 CLAUDE.md가 로드되지 않고, 상대 경로로 파일에 접근할 수 없습니다. 반드시 프로젝트 폴더로 cd 이동한 뒤 실행하세요.
CLAUDE.md 파일이 전체 하나인가요, 아니면 폴더마다 따로 있나요? 두 종류가 동시에 적용됩니다. 전역(~/.claude/CLAUDE.md)은 어디서 실행해도 항상 로드되며 모든 프로젝트에 공통 적용됩니다. 프로젝트별([프로젝트 폴더]/CLAUDE.md)은 그 폴더에서 시작할 때만 로드됩니다. 내용이 겹치면 프로젝트별이 우선합니다.
Claude 실행 중에 ! cd /다른폴더로 이동하면 안 되나요? 효과가 없습니다. ! 명령은 서브쉘에서 실행되기 때문에, 서브쉘이 종료되면 Claude의 작업 경로는 그대로입니다. 이는 Unix/macOS의 근본 특성(자식 프로세스는 부모 프로세스의 경로를 변경 불가)으로, 우회 방법이 없습니다. /exit로 종료 후 올바른 폴더에서 다시 시작하세요.
"이 폴더로 이동해줘"라고 말로 하면 안 되나요? Claude가 ! cd를 실행하더라도 위와 같은 이유로 실제 작업 경로는 바뀌지 않습니다. 단, 다른 폴더의 파일을 절대 경로로 읽거나 쓰는 것은 가능합니다. 프로젝트 전환이 필요하면 Claude를 재시작하세요.
작업 후 "저장해줘"라고 안 하고 그냥 종료하면 파일이 날아가나요? 아니요. Claude가 파일을 편집하거나 생성하면 즉시 디스크에 저장됩니다. 별도로 저장을 요청할 필요가 없습니다. 단, git 커밋은 자동이 아니므로 버전 관리가 필요하면 직접 하거나 Claude에게 요청하세요. 대화 내용은 claude --continue(-c)로 약 3일간 재개할 수 있습니다.

8. 프로젝트 실전 워크플로우

새 프로젝트를 시작할 때부터 종료까지의 전체 흐름입니다. 처음에는 이 순서를 그대로 따라보세요.

준비
STEP 1

프로젝트 폴더 생성

논문·프로젝트마다 별도 폴더를 만드세요. 권장 구조: 01_literature/ 02_data/ 03_analysis/ 04_writing/

준비
STEP 2

CLAUDE.md 작성 (선택이지만 강력 권장)

연구 주제, 현재 단계, 분석 환경, 논문 스타일을 적어두면 매 세션마다 같은 설명을 반복하지 않아도 됩니다.

📋 CLAUDE.md 작성 방법 보기 ↓

시작
STEP 3

터미널 열기 → cd [프로젝트 폴더 경로]

반드시 프로젝트 폴더 안으로 이동한 뒤 다음 단계로 넘어가세요. pwd로 현재 위치를 확인할 수 있습니다.

시작
STEP 4

claude 입력 → Claude Code 실행

CLAUDE.md가 있으면 자동으로 로드됩니다. 시작 화면에서 Working directory 경로가 올바른지 확인하세요.

작업
STEP 5

오늘의 작업 지시 + 이해 확인

작업을 지시한 뒤 "여기까지 이해했어? 오늘 목표 한 줄로 요약해줘."라고 확인하면 엉뚱한 방향으로 진행되는 걸 초반에 잡을 수 있습니다.

작업
STEP 6

작업 진행 — 중간 방향 확인 & /compact

복잡한 지시 후 "이 방향 맞아?"를 물어보세요. 대화가 길어지면 /compact로 컨텍스트를 압축해 속도를 유지하세요.

저장
STEP 7

파일은 자동 저장 — git commit은 선택

Claude가 편집·생성한 파일은 즉시 디스크에 저장됩니다. 별도 저장 요청 불필요. 중요한 변경이 있다면 "지금까지 작업 git commit 해줘"라고 요청하세요.

종료
STEP 8

/exit 입력 → 터미널 닫기

다음 세션에서 이어가려면 claude --continue (-c)로 약 3일 이내 대화를 재개할 수 있습니다.

💬 "여기까지 이해했을까?" — 이해 확인 프롬프트 모음

Claude에게 작업을 지시한 후, 이해도와 방향을 중간에 확인하면 실수와 낭비를 줄일 수 있습니다.

상황확인 프롬프트 예시
작업 시작 전 "오늘 목표가 뭔지 한 줄 요약해줘. 맥락 맞아?"
복잡한 지시 후 "이 방식으로 진행하면 결과물이 어떻게 나와? 제대로 이해한 거야?"
효율성 점검 "지금 접근법이 제일 효율적이야? 더 빠른 방법 있으면 말해줘."
작업 완료 후 "혹시 빠진 부분이나 추가로 확인할 게 있어?"
✅ 이 장을 마쳤다면

프로젝트 폴더가 구성되어 있고, CLAUDE.md가 작성되어 있으며, Claude Code를 프로젝트 폴더에서 시작하는 방법을 알고 있어야 합니다. 이제 단축키와 Claude Code 기본 조작법을 익혀봅니다.

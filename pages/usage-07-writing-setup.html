논문작성 세팅

활용 07  문체 지정, Skill 설치, 출력 형식, CLAUDE.md 논문 특화 설정

논문 작성에 Claude를 본격적으로 투입하기 전에 문체, 형식, 출력 방식을 미리 설정해두면 매번 같은 지시를 반복할 필요가 없습니다. 이 장에서는 논문 작성을 위한 최적 환경을 구성하는 방법을 다룹니다.

1. 논문 작성용 CLAUDE.md 업그레이드

활용 01에서 작성한 기본 CLAUDE.md에 논문 작성 관련 지시사항을 추가합니다. 아래 내용을 기존 CLAUDE.md에 붙여넣거나, 처음부터 논문 특화 버전으로 작성하세요.

CLAUDE.md — 논문 작성 섹션 추가
## 논문 작성 설정 ### 문체 규칙 - 서술 인칭: 3인칭 (연구자는 → 본 연구는, 연구자가 → 본 연구에서) - 시제: 현재형 원칙 (결과 서술은 과거형 허용) - 수동태: 지양 (능동 구문 선호) - 문단: 4-8문장, 각 문단은 주제문으로 시작 - AI 문체 지양: "흥미롭게도", "중요하게도", "~라고 할 수 있다" 등 반복 금지 - 한자어: 과도한 한자어 사용 자제, 한글 풀어쓰기 우선 ### 인용 형식 - 스타일: APA 7판 - 본문 인용: (저자, 연도) 또는 저자(연도) 형식 - 직접 인용: 40자 이상이면 블록 인용 처리 - 참고문헌: 알파벳/가나다 순 혼합 — 한국어 먼저, 영어 다음 - 참고문헌 파일: 01_literature/references.bib ### 출력 형식 - 초안: 마크다운 (.md) → 04_writing/ 폴더에 저장 - 표: 마크다운 파이프 표 형식 - 수식: LaTeX 수식 표기 ($...$ 또는 $$...$$) - 최종 제출: Word (.docx) 변환은 Pandoc 사용 ### 논문 현재 상태 - 완료: 1장 서론, 2장 이론적 배경 - 진행중: 3장 연구방법 - 미작성: 4장 결과, 5장 논의, 참고문헌 ### 목표 학술지 투고 규정 - 학술지: 교육학연구 (한국교육학회) - 글자수: 본문 20,000자 이내 - 표/그림: 본문에 삽입, APA 형식 번호 및 제목 - 초록: 한국어 600자 + 영문 250 words

2. 학술 문체 교정 설정

Claude가 생성한 텍스트에는 종종 "AI 문체"가 섞입니다. CLAUDE.md에 구체적인 금지 표현을 명시하면 더 자연스러운 학술 문체가 나옵니다.

피해야 할 AI 문체 패턴

AI 문체 표현 자연스러운 학술 표현
"흥미롭게도", "주목할 만하게도" 삭제하거나 해당 내용 자체로 표현
"중요하게도", "특히 중요한 것은" 삭제 (독자가 스스로 중요성 판단)
"~라고 할 수 있다", "~로 볼 수 있다" "~이다", "~나타났다" (단정적 표현)
"본 연구는 매우 중요한 시사점을" 구체적으로 어떤 시사점인지 서술
"먼저 ... 다음으로 ... 마지막으로" 부제목이나 번호로 구조화
과도한 반복 (같은 표현 3회 이상) 유의어 활용 또는 문장 재구성
✍️ 문체 교정 프롬프트 예시

04_writing/draft_intro.md 를 읽고 AI 문체("흥미롭게도", "주목할 만하게도", "~라고 할 수 있다" 등)를 자연스러운 학술 문체로 교정해줘. 내용은 바꾸지 말고 표현만 수정해줘. 수정 전/후를 비교해서 보여준 다음에 파일을 업데이트해줘.

3. 논문 작성 Skill 활용

Skill은 Claude에게 특정 작업 방식을 알려주는 지침 파일입니다. 이미 설치된 학술 관련 Skill을 활용하면 논문 작성 품질이 높아집니다. Skill이 처음이라면 → 고급 03 커스텀 Skill 제작에서 개념을 먼저 확인하세요.

4. 출력 형식 설정

논문 작성 흐름에 따라 최적의 출력 형식이 다릅니다. 아래를 참고해서 작업 단계별로 적절한 형식을 사용하세요.

.md (Markdown)
초안 작성·수정에 최적. Claude가 기본으로 생성. 표, 제목, 인용 형식 유지.
초안 단계 권장
.docx (Word)
최종 제출용. Pandoc으로 .md에서 변환. 학술지 제출 형식.
최종 제출 전
.tex (LaTeX)
수식이 많은 논문에 적합. Claude가 LaTeX 코드를 직접 생성.
수식 중심 논문
.csv / .md (표)
APA 형식 표. CSV는 Excel에서 편집 가능, MD는 논문 직접 삽입.
분석 결과 표

마크다운 → Word 변환 (Pandoc)

✍️ 프롬프트 예시 — Word 변환

04_writing/draft_full.md 를 Word 파일로 변환하는 Pandoc 명령어를 만들어줘. APA 형식 참고문헌을 자동으로 처리하고, 01_literature/references.bib 을 사용해줘. 결과 파일은 04_writing/submission_draft.docx 로 저장.

📋 Claude가 생성하는 명령어 예시

터미널에서 아래 명령어를 실행하세요. (Pandoc이 설치되어 있어야 합니다)

pandoc 04_writing/draft_full.md \
  --bibliography=01_literature/references.bib \
  --csl=apa.csl \
  -o 04_writing/submission_draft.docx \
  --reference-doc=template.docx

Pandoc 설치: brew install pandoc (Mac) 또는 pandoc.org에서 다운로드 (Windows)

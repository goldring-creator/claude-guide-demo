Claude API 시작하기

고급 06  Python 코드에서 Claude를 직접 호출해 논문 분류·인터뷰 코딩 등 대규모 연구 작업을 자동화합니다

지금까지 배운 Claude Code는 터미널에서 대화하는 방식입니다. API(Application Programming Interface)는 한 단계 더 나아가, Python 코드 안에서 Claude를 직접 호출하는 방법입니다. 버튼을 클릭하는 대신 코드 한 줄로 Claude에게 요청을 보낼 수 있어서, 수십 · 수백 건의 반복 작업을 완전히 자동화할 수 있습니다.

💡 이 섹션의 전제 조건

Python이 설치되어 있지 않아도 됩니다. 이 가이드에서 설치 방법까지 안내합니다. 코딩 경험이 전혀 없어도 제공하는 예제 코드를 복사해서 바로 실행할 수 있습니다.

1. API vs Claude Code — 언제 API가 필요한가

Claude Code (CLI)
터미널 대화 방식
  • 터미널에서 직접 대화
  • 파일 읽기·쓰기, 코드 실행
  • 1~2개 작업을 그때그때 처리
  • 월 정액 구독 (Pro/Max)
  • 코딩 지식 불필요
Anthropic API
코드에서 직접 호출
  • Python 스크립트에서 호출
  • CSV·JSON 등 데이터 파일 처리
  • 수십~수백 건 반복 처리 자동화
  • 사용한 만큼 과금 (토큰 기반)
  • Python 기초 필요

이런 상황에서 API를 사용합니다

연구 상황API 사용 이유
논문 50편의 제목·초록을 주제별로 분류해야 한다 Claude Code로는 50번 직접 붙여넣어야 하지만, API는 코드 한 번 실행으로 자동 처리
인터뷰 전사본 20개를 같은 기준으로 코딩해야 한다 동일한 코딩 기준을 일관되게 적용하며 결과를 CSV로 자동 저장
설문 응답 1,000건에서 주요 키워드를 추출해야 한다 반복 작업을 밤새 자동으로 처리 — 다음날 결과 파일만 확인
연구팀이 함께 쓰는 자동화 도구를 만들고 싶다 API로 만든 스크립트를 팀원과 공유해 같은 방식으로 분석
💡 처음에는 Claude Code, 반복 작업은 API

분석 방법을 Claude Code로 먼저 실험해보고, 확정된 방법을 API 스크립트로 만들어 대량 처리하는 흐름이 가장 효율적입니다.

2. API 키 발급 — Anthropic Console

API를 사용하려면 Anthropic이 발급하는 API 키가 필요합니다. 자물쇠 비밀번호처럼, 내 계정임을 증명하고 사용량을 추적하는 고유한 문자열입니다.

  1. Anthropic Console 접속

    console.anthropic.com 에 접속합니다. claude.ai와 별도 사이트입니다. 기존 Anthropic 계정으로 로그인하거나 새로 가입합니다.

  2. API 키 생성

    좌측 메뉴에서 API Keys를 클릭합니다. + Create Key 버튼을 누르고 이름을 입력합니다 (예: research-project). 생성된 키가 화면에 표시됩니다.

    ⚠️ 키는 지금만 볼 수 있습니다

    API 키는 생성 직후 한 번만 전체가 표시됩니다. 반드시 지금 복사해서 안전한 곳에 저장하세요. 창을 닫으면 다시 볼 수 없어 새 키를 만들어야 합니다.

  3. .env 파일에 저장

    프로젝트 폴더에 .env 파일을 만들고 아래처럼 저장합니다. sk-ant-로 시작하는 문자열이 실제 키입니다.

    # .env 파일 내용
ANTHROPIC_API_KEY=sk-ant-여기에_실제_키를_붙여넣기
    ⚠️ .env 파일은 절대 Git에 올리지 마세요

    API 키가 GitHub에 공개되면 타인이 내 계정으로 비용을 발생시킬 수 있습니다. .gitignore 파일에 반드시 .env를 추가하세요.

    # .gitignore 파일에 추가
.env

  4. 크레딧 충전 (신규 계정)

    Console의 Billing 메뉴에서 크레딧을 충전합니다. 처음에는 $5~10로 시작해보세요. 논문 분류·코딩 작업에는 소량으로도 충분합니다. 충전 없이는 API 호출이 되지 않습니다.

3. Python 환경 준비

Python 설치 확인

터미널(Mac: 터미널 앱, Windows: 명령 프롬프트)을 열고 아래 명령어를 실행합니다.

python3 --version

버전 번호(예: Python 3.11.4)가 출력되면 이미 설치되어 있습니다. command not found 오류가 나면 Python을 먼저 설치해야 합니다.

💡 Python 설치 방법

python.org/downloads 에서 최신 버전을 다운로드해 설치합니다. Windows에서는 설치 중 "Add Python to PATH" 옵션을 반드시 체크하세요.

필요한 라이브러리 설치

터미널에서 아래 명령어를 실행합니다. anthropic은 Claude API 라이브러리, python-dotenv는 .env 파일을 읽어오는 라이브러리입니다.

pip3 install anthropic python-dotenv

설치가 완료되면 Successfully installed 메시지가 출력됩니다.

💡 pandas도 함께 설치하세요

CSV 파일을 처리하려면 pandas 라이브러리도 필요합니다. 지금 함께 설치해두면 편합니다.

pip3 install anthropic python-dotenv pandas

4. 첫 번째 API 호출

아래 코드를 test_api.py라는 이름으로 프로젝트 폴더에 저장합니다. .env 파일도 같은 폴더에 있어야 합니다.

from dotenv import load_dotenv
import anthropic

# .env 파일에서 API 키 불러오기
load_dotenv()

# Claude API 클라이언트 만들기
client = anthropic.Anthropic()

# Claude에게 메시지 보내기
response = client.messages.create(
    model="claude-haiku-4-5-20251001",   # 가장 빠르고 저렴한 모델
    max_tokens=256,                    # 응답 최대 길이
    messages=[
        {"role": "user", "content": "안녕하세요! 교육학 연구자 AI 도우미가 맞나요?"}
    ]
)

# 응답 출력
print(response.content[0].text)

파일을 저장한 후 터미널에서 실행합니다.

python3 test_api.py

Claude의 응답이 터미널에 출력되면 API 연결이 정상입니다.

코드 각 줄 설명

코드하는 일
load_dotenv() .env 파일을 읽어 ANTHROPIC_API_KEY 값을 자동으로 불러옵니다
anthropic.Anthropic() API 키를 사용해 Claude와 통신할 준비를 합니다
model=... 어떤 Claude 모델을 쓸지 지정합니다. 테스트와 반복 작업에는 Haiku가 적합합니다
max_tokens=256 응답 길이 상한선입니다. 짧은 답변이면 256, 긴 글이면 1024~4096으로 조정합니다
response.content[0].text Claude의 응답 텍스트를 꺼냅니다

5. 연구 자동화 예시

예시 1 — 논문 초록 한 줄 요약

영문 초록을 넣으면 한국어 한 줄 요약을 반환합니다. 여러 논문을 반복 처리할 때의 기본 패턴입니다.

from dotenv import load_dotenv
import anthropic

load_dotenv()
client = anthropic.Anthropic()

def summarize_abstract(abstract: str) -> str:
    """영문 초록을 받아 한국어 한 줄 요약을 반환합니다"""
    response = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=150,
        messages=[{
            "role": "user",
            "content": f"다음 영문 초록을 한국어 한 문장으로 요약하세요.\n\n{abstract}"
        }]
    )
    return response.content[0].text.strip()

# 사용 예시
abstract = """This study examines the relationship between teacher self-efficacy
and student academic achievement in elementary schools..."""

summary = summarize_abstract(abstract)
print(summary)

예시 2 — CSV 논문 목록 자동 주제 분류

제목과 초록이 담긴 CSV 파일을 읽어, 각 논문을 지정한 주제로 분류하고 결과를 새 CSV로 저장합니다.

💡 CSV 파일 형식

입력 파일 papers.csv에는 title(제목)과 abstract(초록) 열이 있어야 합니다. 열 이름이 다르면 코드의 row["title"] 부분을 실제 열 이름으로 바꾸세요.

from dotenv import load_dotenv
import anthropic
import pandas as pd
import time

load_dotenv()
client = anthropic.Anthropic()

# 분류 기준 — 연구 주제에 맞게 수정하세요
CATEGORIES = ["교수법", "교육과정", "교육평가", "교사교육",
              "학습동기", "특수교육", "교육정책", "기타"]

def classify_paper(title: str, abstract: str) -> str:
    """논문의 연구 주제를 분류합니다"""
    categories_str = ", ".join(CATEGORIES)
    response = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=30,   # 짧은 답변이므로 max_tokens를 낮게 설정
        messages=[{
            "role": "user",
            "content": f"""다음 논문의 연구 주제를 아래 분류 중 하나로만 답하세요.
분류: {categories_str}

제목: {title}
초록: {abstract[:500]}

분류 결과(하나만):"""
        }]
    )
    result = response.content[0].text.strip()
    # 분류 결과가 목록에 없으면 "기타"로 처리
    return result if result in CATEGORIES else "기타"

# CSV 파일 읽기
df = pd.read_csv("papers.csv")
results = []

for i, row in df.iterrows():
    print(f"처리 중: {i+1}/{len(df)} — {row['title'][:40]}...")
    category = classify_paper(row["title"], row["abstract"])
    results.append(category)
    time.sleep(0.3)   # API 호출 간격 (과도한 요청 방지)

# 결과 저장
df["category"] = results
df.to_csv("papers_classified.csv", index=False)
print("완료! papers_classified.csv 저장됨")

예시 3 — 인터뷰 발췌문 자동 코딩

인터뷰 발췌문 텍스트를 넣으면 미리 정의한 코드 목록 중 하나로 분류합니다.

def code_excerpt(excerpt: str, codes: list) -> str:
    """인터뷰 발췌문에 코드를 부여합니다"""
    codes_str = "\n".join(f"- {c}" for c in codes)
    response = client.messages.create(
        model="claude-haiku-4-5-20251001",
        max_tokens=100,
        messages=[{
            "role": "user",
            "content": f"""다음 인터뷰 발췌문에 가장 적합한 코드를 아래 목록에서 선택하세요.
여러 코드가 해당하면 쉼표로 구분해 모두 작성하세요.

코드 목록:
{codes_str}

발췌문:
"{excerpt}"

적용 코드:"""
        }]
    )
    return response.content[0].text.strip()

# 사용 예시
my_codes = ["교사 효능감", "수업 준비 부담", "동료 지원", "제도적 장벽", "직무 만족"]
excerpt = "수업 준비하는 데 너무 많은 시간이 걸려서, 옆 선생님한테 물어보면서 같이 해결하고 있어요."

result = code_excerpt(excerpt, my_codes)
print(f"부여된 코드: {result}")

6. 비용·한도 관리

토큰이란?

API 비용은 사용한 토큰(token) 수에 따라 청구됩니다. 토큰은 단어와 비슷한 단위입니다. 한국어는 영어보다 토큰 수가 많이 필요한 편입니다.

  • 영어 약 1,000단어 ≈ 1,300 토큰
  • 한국어 약 1,000자 ≈ 1,500~2,000 토큰
  • 입력 토큰(내가 보낸 프롬프트) + 출력 토큰(Claude의 응답) 합산 청구

모델별 비용 비교

모델특징상대적 비용추천 용도
claude-haiku-4-5-20251001 빠름, 저렴 ★ (가장 저렴) 대량 분류·코딩 자동화, 간단한 요약
claude-sonnet-4-6 균형 ★★★ 복잡한 분석, 긴 텍스트 요약
claude-opus-4-7 최고 품질 ★★★★★ 높은 정확도가 필요한 소량 작업

정확한 요금은 anthropic.com/pricing에서 확인하세요. 요금은 변경될 수 있습니다.

💡 비용 절감 팁
  • 반복 작업에는 Haiku를 기본으로 사용하세요. 품질 차이가 크지 않을 때가 많습니다.
  • 초록을 통째로 보내지 말고 abstract[:500]처럼 앞 500자만 잘라 보내세요.
  • 먼저 5~10건만 테스트해서 결과 품질을 확인한 후 전체를 처리하세요.
  • max_tokens를 실제 필요한 만큼만 설정하세요 (짧은 분류 결과라면 30~100이면 충분).

Console에서 사용량 확인

console.anthropic.com → Usage 메뉴에서 날짜별 토큰 사용량과 비용을 확인할 수 있습니다.

월 예산 한도 설정

Console의 Billing → Usage Limits 에서 월별 지출 한도를 설정할 수 있습니다. 한도를 초과하면 API 호출이 차단되어 예상치 못한 청구를 막을 수 있습니다.

💡 처음엔 $5~10 한도로 시작

논문 100편을 Haiku로 분류하는 데 보통 $0.1~0.5 수준입니다. $10 한도면 대부분의 연구 자동화 실험에 충분합니다.

흔한 오류와 해결 방법

오류 메시지원인해결
AuthenticationError API 키가 잘못됐거나 .env 파일 위치 오류 .env 파일이 Python 스크립트와 같은 폴더에 있는지, 키가 정확한지 확인
RateLimitError 짧은 시간에 API를 너무 많이 호출 반복문 안에 time.sleep(0.5)를 추가해 호출 간격을 둡니다
overloaded_error Anthropic 서버 과부하 (일시적) 잠시 후 다시 시도합니다. 자동 재시도 코드를 추가해도 됩니다
ModuleNotFoundError: anthropic anthropic 라이브러리 미설치 터미널에서 pip3 install anthropic 실행

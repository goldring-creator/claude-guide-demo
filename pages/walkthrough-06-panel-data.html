패널데이터란?

패널데이터는 같은 개인(또는 집단)을 여러 시점에 걸쳐 반복 측정한 데이터입니다. 횡단면 데이터(1회 측정)와 달리 시간의 흐름에 따른 변화를 분석할 수 있습니다.

2
데이터 전처리 코드 작성Claude

분석 전에 Wide → Long 변환, 변수명 정리, 결측값 처리 코드가 필요합니다.

프롬프트

R 코드를 작성해 주세요. 데이터는 Wide format이며 Long format으로 변환이 필요합니다.

- 파일명: panel_data.csv
- ID 변수: id
- 시점 변수: y1_, y2_, y3_ 접두사로 구분
- 변환 후 시점 변수 이름: wave (1, 2, 3)
- 필요 패키지: tidyverse

변환 후 각 시점별 결측값 수를 출력하는 코드도 추가해 주세요.

Claude — R 코드 예시
Claude

library(tidyverse) # 데이터 로드 df <- read.csv("panel_data.csv") # Wide → Long 변환 df_long <- df %>% pivot_longer( cols = starts_with(c("y1_", "y2_", "y3_")), names_to = c("wave", ".value"), names_pattern = "(y\\d+)_(.*)" ) %>% mutate(wave = as.integer(str_extract(wave, "\\d+"))) # 시점별 결측값 확인 df_long %>% group_by(wave) %>% summarise(across(everything(), ~sum(is.na(.))))

다층모형(HLM) 분석 전 과정

연구 질문 설계부터 ICC 확인, 모형 구축, 결과 해석, 논문 작성까지 — Claude와 함께 위계적 선형 모형을 처음부터 끝까지 돌려봅니다.

이 따라하기가 필요한 연구자

학생이 학교에 내재(nested)되어 있거나, 측정 시점이 개인에 내재되어 있는 위계적 데이터 구조를 가진 분들에게 적합합니다. R의 lme4 패키지 기본 문법을 알고 있다고 가정합니다. HLM 이론 배경은 활용 — 통계 분석 지원을 먼저 확인하세요.

왜 HLM인가

학생(Level 1)이 학교(Level 2)에 속해 있는 경우, 같은 학교 학생들의 점수는 서로 독립적이지 않습니다. 일반 회귀분석은 이 비독립성(non-independence)을 무시해서 1종 오류율을 높이고 표준오차를 과소 추정합니다. HLM은 이 구조를 명시적으로 모형화합니다.

1
데이터 구조를 Claude에게 설명하고 분석 설계 받기
나 → Claude

분석을 시작하기 전에, 데이터 구조와 연구 질문을 Claude에게 설명하면 최적의 모형 전략을 설계해 줍니다. 활용 01 — 프로젝트 설정에서 배운 것처럼 Project 컨텍스트에 데이터 코드북을 미리 올려두면 더 정확한 안내를 받을 수 있습니다.

Claude — HLM 설계 상담
나 (연구자)

데이터: 30개 학교, 학교당 평균 24명 학생, 총 712명. 종속변수: 수학 성취도 (0~100점) L1 예측변수: 학생 SES (1~5), 선행학력 (표준화) L2 예측변수: 학교 유형(공립/사립), 학교 평균 SES 연구 질문: ① 학생 SES가 성취도에 미치는 영향이 유의한가? ② 학교 유형이 SES-성취도 관계를 조절하는가? 어떤 순서로 모형을 구축해야 하나요?

Claude

위계적 데이터 구조에서 교차효과(cross-level interaction)를 검증하는 전형적인 2수준 HLM입니다. 권장 모형 구축 순서: 1. Null Model (무조건 모형) → ICC 산출, HLM 사용 정당화 2. L1 예측변수 투입 → 학생 SES, 선행학력 고정효과 3. L2 예측변수 투입 → 학교 유형, 학교 평균 SES 4. 무선 기울기 모형 → SES 기울기를 무선효과로 지정 5. 교차효과 투입 → 학교 유형 × 학생 SES 각 단계에서 AIC 비교와 LRT(Likelihood Ratio Test)로 모형 개선 여부를 확인하시면 됩니다. 우선 lme4 패키지로 Null Model부터 시작해 볼까요?

팁 — 집단 수(Level 2 N)가 중요합니다

교차효과를 안정적으로 추정하려면 Level 2 집단이 최소 30개 이상 필요합니다. Claude에게 샘플 크기를 반드시 알려주세요. 집단 수가 적으면 무선 기울기 모형이 수렴하지 않을 수 있습니다.

2
Null Model로 ICC 산출 — HLM 사용 정당화
Claude 생성

ICC(급내상관계수)는 전체 분산 중 집단 간 차이가 차지하는 비율입니다. HLM을 사용해야 하는지를 수치로 보여주는 첫 번째 핵심 결과입니다.

R Console — Null Model
나 (연구자)

Null Model R 코드 작성해줘. ICC도 바로 산출되게.

Claude → R 코드

library(lme4) library(lmerTest) library(performance) # Null Model (무조건 모형) m0 <- lmer(math_score ~ 1 + (1 | school_id), data = df, REML = TRUE) summary(m0) # ICC 자동 산출 icc(m0) # 분산 성분 직접 확인 vc <- as.data.frame(VarCorr(m0)) tau00 <- vc[vc$grp == "school_id", "vcov"] # L2 분산 sigma2 <- vc[vc$grp == "Residual", "vcov"] # L1 분산 icc_manual <- tau00 / (tau00 + sigma2) cat("ICC =", round(icc_manual, 3), "\n")

ICC 해석 기준 — 이 연구의 예상 결과: ICC = 0.18
ICC 18%
0% 5% (HLM 필요 기준) 50% 100%
ICC < 0.05 → 일반 회귀분석 가능 ICC 0.05~0.15 → HLM 권장 ICC > 0.15 → HLM 필수

ICC = 0.18이면 수학 성취도 분산의 18%가 학교 간 차이로 설명된다는 의미입니다. HLM 사용이 통계적으로 정당화됩니다. Claude에게 이 수치를 논문 방법론 섹션에 쓸 문장으로 변환해 달라고 요청하세요.

3
단계적 모형 구축 — L1 → L2 → 교차효과
Claude 생성

Null Model 이후에는 이론에 따라 변수를 단계적으로 투입합니다. Claude는 각 모형의 R 코드와 함께 어떤 가정을 검토해야 하는지 안내합니다.

M0
Null Model (무조건 모형)
절편만 존재. ICC 산출 목적.
math ~ 1 + (1 | school_id)
M1
무조건 기울기 모형
L1 예측변수 투입 (고정 기울기). SES, 선행학력의 주효과 추정.
math ~ ses + prior + (1 | school_id)
M2
무선 기울기 모형
SES 기울기를 무선효과로 지정. 학교마다 SES 효과가 다를 수 있음.
math ~ ses + prior + (1 + ses | school_id)
M3
조건부 모형 (교차효과)
L2 변수 및 교차효과 투입. 학교 유형이 SES 기울기를 조절하는지 검증.
math ~ ses * school_type + prior + school_ses + (1 + ses | school_id)
R Console — 단계적 모형 구축 및 비교
나 (연구자)

M1~M3 코드 전부 작성하고, 마지막에 anova()로 모형 비교까지 해줘.

Claude → R 코드

# M1: L1 고정 기울기 m1 <- lmer(math_score ~ ses + prior_score + (1 | school_id), data = df, REML = FALSE) # ML for model comparison # M2: SES 무선 기울기 허용 m2 <- lmer(math_score ~ ses + prior_score + (1 + ses | school_id), data = df, REML = FALSE) # M3: L2 변수 + 교차효과 투입 m3 <- lmer(math_score ~ ses * school_type + prior_score + school_avg_ses + (1 + ses | school_id), data = df, REML = FALSE) # 모형 비교 (LRT) anova(m0, m1, m2, m3) # 최종 모형 REML 재추정 m3_final <- update(m3, REML = TRUE) summary(m3_final)

주의 — REML vs ML

모형 비교(anova)에는 REML = FALSE(ML 추정)를 사용해야 합니다. 최종 계수 추정에는 REML = TRUE로 돌아오세요. Claude에게 코드 요청 시 이 사항을 명시하거나, 코드를 받은 후 확인하세요.

4
결과 해석 — 고정효과·무선효과·교차효과
나 → Claude

summary(m3_final) 출력을 Claude에 붙여넣고 해석을 요청합니다. 고정효과, 무선효과 분산, 교차효과 패턴을 모두 설명해 줍니다.

Claude — 결과 해석
나 (연구자)

summary 출력 붙여넣음... Fixed effects: ses = 3.21 (p < .001), school_type(사립) = 8.45 (p = .002), ses:school_type(사립) = -1.87 (p = .031) Random effects: var(intercept)=24.3, var(ses)=1.8, cov(int,ses)=-0.43, residual=58.2 이 결과 어떻게 해석하면 돼?

Claude

주요 결과 해석: [고정효과] • SES 주효과(β=3.21, p<.001): 공립학교에서 SES 1단위 상승 시 수학 성취도 3.21점 증가 (기준 집단: 공립) • 학교 유형 주효과(β=8.45, p=.002): SES 평균 수준에서 사립학교 학생이 공립보다 8.45점 높음 • 교차효과(β=-1.87, p=.031): 사립학교에서 SES 효과가 공립보다 1.87점 약함. 즉 사립학교에서는 SES 격차가 성취도에 덜 반영됨 → 형평성 효과 가능성 [무선효과] • 절편 분산(24.3): 학교 간 기저 성취 수준 차이 존재 • 기울기 분산(1.8): 학교마다 SES 효과 크기가 다름 • 음의 공분산(-0.43): 기저 성취가 높은 학교일수록 SES 효과가 약한 경향 (보상 패턴)

교차효과 "두 집단에서 SES 효과 기울기를 텍스트로 비교해줘" 결과 + 논의 섹션

완료 체크리스트

  • Null Model의 ICC가 0.05 이상으로 HLM 사용 정당화됨
  • 변수 센터링 전략 결정 (집단-내 센터링 vs 전체 평균 센터링)
  • 단계적 모형 구축 시 REML=FALSE로 ML 추정 사용
  • LRT(anova)로 각 단계 모형 개선 검증
  • 최종 모형 REML=TRUE로 재추정 후 계수 보고
  • 무선효과 공분산 구조 이론적으로 설명 가능한지 확인
  • 교차효과 상호작용 플롯으로 시각화
  • 방법론 섹션에 ICC, 모형 단계, 소프트웨어 버전 명시
이 따라하기를 마치면

위계적 데이터 구조를 올바르게 다루는 HLM 분석의 전 과정을 Claude와 함께 수행할 수 있습니다. ICC로 HLM 정당화 → 단계적 모형 구축 → 교차효과 해석 → 논문 작성까지 이어지는 파이프라인을 반복해서 활용하세요.
